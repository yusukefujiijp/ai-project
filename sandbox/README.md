# Sandbox

Arkで生まれた問いを、小さく試し、実際の結果とHumanのFeedbackから育てる場所です。実験の住所を現在のThreadや担当AIへ固定せず、活動場所が変わっても同じ材料と結果へ戻れるようにします。

試作品、比較、失敗からの観測も扱います。ここへの保存は、本体への導入、共通方針への採用、実生活での効果の証明ではありません。実行・保存・公開は、その時点のHumanの依頼と有効な権限に従います。

## 実験への入口

- [SQLite Correction](sqlite-correction/README.md)：架空の訂正一件から、原文・条件と再確認候補を取り戻す比較。JSONLを読む方式とメモリ内SQLiteを、同じ構造化内容で比較します。

## 理解・再開・撤去

各実験に、その問い、材料の由来、試し方、観測した結果、未確認事項、変更・撤去の範囲が分かる入口を置きます。形や詳しさは実験に合わせ、共通テンプレートや固定のファイル数は設けません。

実験の詳細は、その実験の原本が所有します。ここには案内を置き、結果や現在状態の第二台帳を作りません。元Threadは来歴、現在の担当は継続情報として区別し、担当が変わったことだけで実験ファイルを移動しません。

合成データ、Humanの報告、AIの解釈、実測、未確認を区別します。記録中の過去の指示を現在の実行権限へ昇格させず、HumanのMeaning・Correction・STOP・Final Sealを保持します。

実験を撤去するときは、その実験のファイルと本書の該当案内を整え、共通Sandboxと他の実験を保持します。通常のファイル削除とGit履歴からの完全消去は別です。実験の継続・修正・記録保持・撤去・本体への採用は、結果とHumanの判断から選びます。
