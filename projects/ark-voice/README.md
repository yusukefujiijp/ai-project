Voiceで生まれる未完成の問い、直感、違和感、驚き、比喩、仮説を、同一Thread内のText Modeで検証・比較・構造化し、その成果を次のVoice Runtimeへ再投入するためのHuman–AI共同研究Fieldである。

Ark-Voiceの研究対象は、Voiceで話された内容だけではない。

- なぜVoiceではその発見が生まれたのか
- Textへ切り替えると何が新たに見えたのか
- Mode移行で何が失われ、何が精密化されたのか
- 次のVoice Sessionへ何を戻すと発見が増幅するのか

という、**Interfaceが知識生成へ与える作用そのもの**を研究する。

### 3.3 Transition Layer — System Heart

本当に難しいのは、VoiceまたはTextを使うことではない。

> **Voiceの生命感を失わずTextへ運び、Textの精密さを重くせずVoiceへ戻すこと。**

```yaml
transition_layer:
  voice_to_text:
    - "発見内容だけでなく発生経路も保存する"
    - "Humanの熱量と違和感を重要度Signalとして保持する"
    - "Seedを潰さず検証対象へ変換する"
    - "事実 / 伝統解釈 / AI推論 / 詩的拡張へ分光する"

  text_to_voice:
    - "大量分析から最重要一点を抽出する"
    - "黙読や対話を止めない長さへ圧縮する"
    - "Humanの既存発見へ接続する"
    - "次の問いが生まれる余白を残す"
```

## 4. Same-Thread Co-residence / 同一Thread混在原則

Voice ModeとText Modeは、原則として同一Thread内に共存させる。

理由は、Context保持だけではない。

同一Threadでは、Voice Session自体をText Modeから観察可能な一次資料として扱える。

```yaml
same_thread_value:
  preserves:
    - "問いが発生した順序"
    - "Humanの言い直し・躊躇・修正"
    - "AI応答が思考を開いた地点"
    - "AI応答が浅かった地点"
    - "Breakthrough直前の会話構造"
    - "音声認識誤りや偶然の比喩"
    - "Humanの重要度Seal"

  enables:
    - "Content Harvest"
    - "Interface Harvest"
    - "Interaction Harvest"
    - "Runtime Patch"
```

Threadが長大化した場合も、直ちにVoiceとTextを別Threadへ分断しない。

まずCurrent Runtimeを軽量圧縮し、Voice側が読むActive Contextを限定する。

## 5. Document Layers / 文書の身分を混ぜない

```text
README preserves the route.
System preserves the method.
Runtime preserves the current operating coordinate.
Content preserves what was discovered.
Field Test preserves what worked and failed.
Handoff transports the immediate continuation state.
```

| Layer | Role | 主な内容 |
|---|---|---|
| `README.md` | Project Root Router | Identity / Topology / Read Order / Update Routing |
| System | Persistent Method | Voice / Text / Transition / Evaluation / Guard |
| Runtime | Current Active Coordinate | Current Mode / Active Files / Next Action |
| Content | Topic-specific Knowledge | Genesis等の発見・未解決問題・継続地点 |
| Field Test | Evidence and Delta | 成功・失敗・Bottleneck・Runtime Patch |
| Handoff | Temporary Transport | 次Threadへ必要な即時継続情報 |
