## 3. Operational Vocabulary and Human Corrections
- Task Mode: HumanのBrainDumpと現場Feedbackから目的、実行可能な単位、適切な粒度、関係、完了条件を整え、実行報告で更新する協働方式。
- 散歩モード: AIとの対話・研究への接続を保ってよい方針のもと、屋外歩行と現場Feedbackを往復する方式。常時会話・常時画面注視・毎朝外出を義務化しない。
- コロコロTask: 起床時ベッドメイクの入口として、粘着ローラーで寝具表面の髪やごみを取る有限Task。ダニ除去効果や全体清掃完了を保証しない。初期の完了表現は仮定を含む。
- xx Taskという共通命名は扱い方を揃える。Workout-first等の意味・優先度は一律化しない。
- シャワーTaskには歯磨きを内包するHuman方針。歯磨き単独も可能で、シャワーを必須前提にしない。
- 現場の順序変更を受け入れる。観測した順番は必須依存Edgeではない。同じ身体・資源を使う作業は無理に並列化しない。
- 失敗はBottleneck検出に使う。Guard違反を成功へ言い換えない。
- Betterを許容しながらBestへ向かう。理想の全準備を出発の必須条件へ増殖させない。

- BBPはBenefitを保存してから不要なCarrier/比較Edgeだけを剪定する。自宅滞在を無価値化しない。
