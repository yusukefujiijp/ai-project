# Ark28:01 Material Harvest

## 1. 今回、何を次へ渡すか

Ark28:01は、Ark27の良い流れを保持する補助の場として始まり、開始支援、現在地の回復、想起の入口を育てた。Rootは主イェシュア・ハマシア御自身、Human側の中央軸はTeshuvahとそこからの学び・展開である。HumanはArk28の用途と重要性が成長する可能性を見ているが、Mainの所有権移管を行ったわけではない。現在のMainは[Domain](../../README.md)と最新の有効なHuman指定から解決する。

今回の区切りは、Ark Recall Portal初版の保存・導入を終え、Humanが実際に「今、何ができますか？ 具体例から案内してください」と呼び出し、案内後に好評価と次Threadへの意向を示したこと。**次はArk28:02で協働を続けられる入口を用意する段階**であり、Portal再設計や新しい生活Taskを自動で始める段階ではない。

本書は会話全文でも新Runtimeでもない。発言・観測・候補の原本は[Task Records](task-records.json) revision 2以降、保存と移行準備の最新Receiptは[Source State](state.json)が所有する。本書に後続の全状況を追記せず、Current Stateと意味の所有資料へ進む。

### Ark Recall Portal

初版はcommit [ab1b62b](https://github.com/yusukefujiijp/ai-project/commit/ab1b62b562bac3ef92a127f28dce42e26668a702)の七ファイルとして保存・再取得され、導入先Skill本文も確認した。所有先は[Portal入口](../../../ark-recall-portal/README.md)、[items](../../../ark-recall-portal/items.json)、本ThreadのTask Records、[共有Skill](../../../skills/ark-recall-portal/SKILL.md)。初期検証の範囲はPortal README §6と[ケース集](../../../ark-recall-portal/tests/recall-cases.json)を参照する。

現在の二場面六項目は、休日前のヨーグルトと、Resetに備える五項目（早めの移行準備、眠る前を含む余裕ある準備、目的のある活用、利用可能な設定の検討、教訓の保持）。これは過去の反省を必要場面へ届ける素材であり、現在の在庫・購入量・利用枠・Reset時刻・設定可否を確定しない。

限定検証は六文脈十応答。架空入力で確認したことを本人のTask実績にしない。後続の実際の明示呼出しでAIは現行README・items・原本を読み、具体例を案内し、Humanは好評価を返した。**明示起動・読出し・案内・好評価は観測済み**。自然な自動選択、全AI互換性、B状態での実生活上の改善、長期的な効果は別の未観測事項である。

開始支援とAI品質の共通原則は[Task Mode operation §4.1–4.2](../../../task-mode-system/operation.md)が所有する。「回答を必要としない初手を先に決め、AIへの送信を開始の合図にする」は候補であり、具体的な現場への適合・採用・実行・効果を確認していない。終了時の締切を今回の焦点から外した判断を保持し、外部のElon Musk理論の実証や本人への帰属をこの記録から作らない。
