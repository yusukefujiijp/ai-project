- 最新Correctionは、有効な完成Prompt作成の接続が残る計画地点でNoneとした誤り。段階完了とGoal達成を分け、今有効な後続を消さない。一方、終了・意図的保留・追加依頼不要も正当であり、常にQueryを捏造しない。
