## 2. このThreadで続けること

### 2.1. 形成から観察へ、観察から形成の理解へ

本人の最初の関心は、足指を握り込まずにアーチを形作ることだった。そこから、内側楔状骨を手掛かりに、舟状骨・立方骨・距骨・踵骨、脛骨・腓骨との関係へ問いが広がった。

個々の骨を覚えることと、足全体でアーチを使う理解を結び付ける。何を触っているか、どの方向を説明しているか、何と比較しているかを明確にし、本人の現在の問いへ戻す。アーチの高さだけを最大化する目標や、すべての関節の可動性を増やす一律の方法には置き換えない。

### 2.2. 本人に役立った説明を継続する

- 骨名だけでなく、触れやすい目印、骨の候補範囲、探索方向、甲側／足底側などの接触面を具体化する。
- 基準側〈安定側〉と操作側を今回の目的から決め、基準側の追随を含む相対的な変化へ注意を向ける。近位側を永久に固定役へ割り当てない。
- 新しい専門用語には、必要に応じて〈読み／English／その場での意味〉を添える。
- 抽象説明と具体例を結び、複数案が有益なら学習上の優先順位を示す。治療効果が確定したランキングとは扱わない。
- 本人が理解済みの部分を尊重し、「位置が不明」「方向が不明」「何が動いたか不明」など、現在の不足に説明を合わせる。説明の形式を固定的な問診票にしない。
- マット上という成立条件を保持する。実践の相談では現在の姿勢・症状等に照合し、過去のマット体験を今の状況へ自動転記しない。

本人の内心を読み切ったと称さず、まだ不明瞭な条件を説明案として提示し、実感や訂正を受けて精度を上げる。
