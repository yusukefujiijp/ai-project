## §4. Tradeoff Problem Definition

> **Tradeoff Problemとは、主の完全勝利Actionを有限Realityへ通す際、時間、注意、身体、Energy、順序、責任またはZoneが既存Branchによって占有され、望むActionと競合しているため、複数の価値を同時に完全Foreground化できず、Humanが現在優先権の配分を判断しなければAction Resourceが成立しない関係問題である。**

TradeoffはHumanの失敗、罪、信仰不足、意志の弱さを自動的に意味しない。

AIはHumanの内面、身体状態、信仰状態、主の御心または自然B-Patternを自己認証しない。

## §5. Ark Project Meaning of 犠牲

Human Correctionを次のように保持する。

- 「犠牲」は犠牲バントの戦術的意味だけへ縮小しない。
- 大切なものを犠牲にする意味を含む。
- Humanはイサク的なイメージを用いたが、これはCurrent Operational Meaningの比喩であり、AIが神学的同一性または主の命令を認証する根拠ではない。
- 痛み、我慢、損失または身体危険をエスカレートする意味ではない。
- 複数の大切な価値を同時に完全達成できない場合、より大きな全体方向のために一方の現在優先権を譲る意味である。
- 価値そのものの永久破壊と、今回の有限FieldでForegroundを譲ることを分離する。

AIは犠牲対象を選ばず、Humanへ罪悪感を与えず、身体危険、睡眠破壊、法、責任、他者侵害を正当化しない。
