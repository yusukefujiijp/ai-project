## 3. Deep Structure of First-Step Friction

### 3.1 First-Step Avoidance Is Often Future-Network Avoidance

表面：

```text
最初の一歩が踏めない
```

深層Candidate：

```text
初手
→ 次手の存在を活性化
→ 順序判断を活性化
→ 完了責任を活性化
→ 失敗処理を活性化
→ 中断時の罪悪感を活性化
→ 終了不明を活性化
→ 身体は「一歩」ではなく「開く全Network」を予測
→ 初手回避が短期的なBranch遮断として機能
```

このため、Taskを一歩へ小さくするだけでは不足する場合がある。一歩の後ろに見えるNetworkを同時に閉じる必要がある。

### 3.2 Hidden Contract Problem

First-Stepが難しいのは、Humanが初手を次のような隠れた契約として感じる可能性があるためである。

```text
始めた
= 最後までやる
= 正しくやる
= 全Branchへ責任を持つ
= 中断してはいけない
= 次の判断も今決める
```

Workout-based InterfaceはこのHidden Contractを次へ書き換える。

```text
始めた
= Guard内の一身体Actionへ入った
= 変形実行してよい
= 部分成功を観測できる
= Completion Signalで一度閉じてよい
= 次のPathはActual後に再計算する
```

### 3.3 Deadline as Permission, Not Only Pressure

締切は開始を強制するだけでなく、止めてよい範囲を保証する。

```text
Deadlineなし
→ Open-ended commitment
→ Exit uncertainty
→ Branch anticipation
→ Start inhibition

Guarded Deadlineあり
→ Bounded commitment
→ Exit guarantee
→ Deferred branches remain closed
→ Start passage opens
```

この意味で、締切Workoutは罰や追込みではなく、**終了許可を先に与えるBoundary**である。
