```text

```

### §5.4 Relation Layer

Task間を少なくとも次で区別する。

- `DEPENDS_ON`：別TaskのOutputを実際に必要とする。
- `CAN_RUN_DURING`：別ExecutorのWait中に進められる。
- `RESUME_ON`：SignalまたはEventで戻る。
- `BLOCKED_BY`：Guard、資源または不明点で止まる。
- `DONE_WHEN`：有限な完了条件。
- `RECONNECT_FROM`：Disconnect後の確認可能なCheckpoint。

Edge Typeを装飾的に増やさない。
