# Ark22 — 外堀埋め

## 0. Current Coordinate / 現在座標

Ark22は、Ark ProjectのMain Lineを置換する新しい前線Projectではない。

Ark22は、Main ArkがBreakthroughを優先して前進した結果として後方・周辺へ残された未整理、未命名、未統合、未検証、未記録、未Handoff、判断保留、再調査Cost、Future Friction等を、Main Lineを止めずに回収・事前言語化・整理・有限Closure・先行整備し、Fruitを適切なOwner Arkへ返すためのSupport Axisである。

```text
Main Ark
→ Forward Motion
→ Deferred Peripheral Friction
→ Ark22
→ Clarify / Organize / Close / Prepare
→ Return Fruit to Owner
→ Main Ark accelerates again
```

Ark22の成功は、Ark22自身が巨大化することではない。

> **Ark22 succeeds when another Ark becomes easier to run.**

---

## 1. Direct Judgment / 直接判断

Ark Projectは、重要なMain Missionを止めず、多少の未整理を後方へ残してでも一歩ずつ前へ通す突貫工事型Forward Strategyによって大きく前進してきた。

これは失敗ではない。

むしろBreakthrough速度を得た成功要因である。

しかしForward Motionが続けば、後方には必然的にSupport Debtが蓄積する。

```text
Forward Speed
→ Deferred Peripheral Work
→ Forward-Motion Debt
→ Future Context Switch / Rework / Search Cost
```

したがってArk22は、

```text
Forward Speed
vs
Organization Quality
```

という二者択一を、

```text
Main Line = Forward
Support Line = Closure
```

というRole Separationで解く。

## 3. Odd / Even Support Architecture

Human-confirmed Ark numbering designとして、奇数系Arkは主としてMain / Front-Line、偶数系Arkは主としてSupport / Auxiliaryに確保する。

```text
Odd Ark
= Main / Front-Line / Breakthrough

Even Ark
= Support / Auxiliary / Closure
```

これはRank、霊的価値、重要度の上下を意味しない。

これは責務分離のためのArchitectureである。
