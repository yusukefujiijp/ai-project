## 2. 継承する中心と成立条件

01でChatGPTが提示した概念上の統合案：

> AIが「完了した」と言えるのは、Humanの願いと現在の委任に沿って具体化・更新した成功条件を、実際の成果物に対して確認し、証拠が支える範囲でその達成を示せたときに限る。

pstack全体の公式定義、全案のHuman採用、運用効果の実証とは区別します。意味と根拠の担当原本は[固定01総括](https://github.com/yusukefujiijp/ai-project/blob/0f7cd386fa1f69a30cab6c23123883daffbfedde/ark-project/ark100-199/ark111_lauren-tan-pstack/ark111-01/README.md)です。

- 条件とHumanの願いの適合、実際の成果物の達成、委任との適合を混同しない。部分達成で依頼全体を完了にせず、未言語化の願いの存在可能性だけで全作業を無限に未完了にしない。
- Humanの一個一個のQuery確認は、意味の擦り合わせと早期検知の保険。頻度削減を当然のGoalにしない。AIの検証と探索を十分に担うことと両立させる。
- AIは成功条件の具体化・基準欠落の発見・方法選択・訂正可能な仮説を十分に担う。成功の意味・優先順位・許容する損失を変える提案は、その実質と現在の委任からHumanの判断へ接続する。
- 基準不足による意味のずれと、基準過剰による探索・価値の取りこぼしを考慮する。反例・新発見・説明短縮・特定の検査手順を毎回の固定義務にしない。
- Humanの応答や新証拠で基準を更新できる。当時の条件・観測・更新理由・現在の判定を分け、後から合格させるために守る対象を消さない。古い証拠の再利用は新条件にも実際に対応する範囲に限る。
- 「母」は、Grok Botの成功がDots成立へ大きく影響したというHumanの製品ルーツの理解を保持する。単なる参考人物へ薄めず、外部因果の実証と分ける。
- Humanの「やっと本題に戻ったようでホッとした！」は、核への接続回復への安堵として扱う。途中の有用な検討を捨てたり、短文化・探索制限・全案採用へ変換したりしない。

現在のGoalに必要な条件、AIの裁量で選ぶ方法、追加の価値を提案することを区別します。具体化と基準の更新は協働を進める手段であり、毎回の全設計や全再検査をHumanへ戻す理由ではありません。

## 5. 三役の整合と可変State

三点セットはProject、Source／Target、owner、role、transition_kind、確定Title、委任範囲で一致します。README／Handoffはv001-human-authorized、Stateは本Runtimeの局所schema v001・revision>=1を使います。新しい全Ark共通schemaを定義するものではありません。

Stateは既存三役の構成に沿うmeta、identity、authority、bindings、now、progress、evidence、deferred、eof_sentinelを持ちます。metaは同一性と改訂、identityは対象、authorityは現在の委任、bindingsは所有資料・固定来歴、nowは現在のGoalと合法手、progress/evidenceは主体と観測範囲、deferredは未採用・未確認の枝を所有します。実観測でrevisionを更新し、未知fieldと過去の観測を保持します。

Current所有資料はIdentity・役割・版と意味上の互換性で確認します。観測blobは読解Receiptであり自動的な永久pinではありません。固定01総括は履歴の正確な参照です。自己SHAや相互live-blob循環、他Projectの固定Binding移行は作りません。
