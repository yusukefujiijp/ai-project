# 【Ark25: Living Torah Project Foundation】

## 0. First 60 Seconds

Ark25は、Torahの辞書、完成済み注解書、AIが自由連想する無制限な解釈集ではない。

Ark25は、Torah五書の既に閉じられたBook–Chapter–Verse座標を安定した外枠として用いながら、各洞察をEvidence、Layer、Status、Human Decision、Revision Lineageを持つClaimとして保存し、現在のAIとFuture AIが既存の意味を破壊せずに訂正・追加・比較・継承できる基盤である。

Core Principle：

> **Freeze the Coordinates, Keep the Hermeneutics Living.**  
> **座標を固定し、解釈は生かしておく。**

最初に固定するのは、解釈の結論ではない。

固定するのは、次の「戻って来られる場所」である。

- どのVerseについてのClaimか。
- 何を主張しているか。
- どのLayerに属するか。
- Evidenceは何か。
- 競合する読みは何か。
- 現在のStatusは何か。
- Humanは何をKeep / Revise / Remove / Pendingとしたか。
- 何が、いつ、なぜ変わったか。

Ark25:01はこのFoundationをHuman Reviewへ提出する最初のSessionであり、Bereshit01:01本文研究そのものはまだ開始しない。

## 9. Status and Human Decision Are Different Axes

Claim Status Candidate：

| Status | Meaning |
|---|---|
| `CORE` | 本文・形態等、現在の基礎Evidenceとして強く保持 |
| `LIVE` | 有力な競合読解を含み、開いた検討対象 |
| `TRADITION` | 歴史的受容として保持 |
| `RELATION` | Text間・神学間・概念間のRelationとして保持 |
| `HOLD` | 興味深いがEvidenceまたは比較が不足 |
| `OUT` | 指定LayerのEvidence Claimとしては採用しない |

Human Decision：

| Decision | Meaning |
|---|---|
| `Keep` | 現在の形で保持 |
| `Revise` | 内容または境界を修正して保持 |
| `Remove` | Active setから除外 |
| `Pending` | Human判断待ち |

`Status`はClaimのProject上の証拠的位置であり、`Human Decision`はHuman authorityの明示である。

AIはStatusを提案できる。Human Decisionを偽造・上書きできない。

`OUT`は信仰的Relationを禁止する判決ではない。例えば「Hebrew-language claimとしてOUT、Symbolic/Messianic relationとしてHOLD」のようにLayerを分離できる。

## 10. AI-New Era: From Probability to Certainty

Ark25における`From Probability to Certainty`は、AIの解釈を無謬化する標語ではない。

AIの生成には創発性、探索力、未知のRelation発見がある。同時に、出力を完全自由にすれば、同じ問いでもLayer、Evidence、結論が混線し、再現性と継承性が失われる。

Ark25が目指すCertaintyは、少なくとも次を再現可能に確定することである。

```text
What verse?
What claim?
What layer?
What evidence?
Whose judgment?
What status?
What changed?
Why changed?
What remains unknown?
```

```yaml
free_for_ai:
  - candidate discovery
  - relation discovery
  - counter-reading generation
  - source comparison proposals
  - explanatory synthesis

bound_for_reproducibility:
  - exact verse address
  - claim identity
  - evidence provenance
  - layer separation
  - status vocabulary
  - Human Decision preservation
  - revision lineage
  - unknown marking
```

> **Creativity inside coordinates; certainty of provenance, not certainty theater.**
