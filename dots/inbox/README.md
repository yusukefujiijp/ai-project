# 原本の新しい住所

このRefでの本文・更新先は [agents/dots/inbox/README.md](../../agents/dots/inbox/README.md)。この旧入口は案内だけを所有する。共有基準mainへの切替と製品側の確認状況は[STR-022](../../control-center/changes/STR-022-dots-agent-location.md)へ戻る。候補Refの存在だけでは実運用の切替を意味しない。

通常のCurrent読取ではリンク先の原本をmetadataから宣言されたExact EOFまで読む。この案内の読了を元本文の全文読解や旧Bindingの成功へ置き換えない。これは自動転送ではなく、旧JSONLへの書込みも転送しない。可変原本の並行追記先を作らない。

移設前の本文は[固定版](https://github.com/yusukefujiijp/ai-project/blob/2dc05496b555638a47a3de2f058c7f632aca773f/dots/inbox/README.md)、blob `43ce94874adc3d1bc6ddb6c5a974dc5c7fd31d9f`。固定commit、明示canonical_path、Identity、版、Exact EOFを要求する契約はその条件に従う。旧住所を明示固定する契約は案内だけで互換と認定せず、必要な版移行を解決する。
