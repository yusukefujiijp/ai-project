# 原本の新しい住所

このRefでの本文・更新先は [agents/dots/logs/README.md](../../agents/dots/logs/README.md)。この旧入口は案内だけを所有する。共有基準mainへの切替と製品側の確認状況は[STR-022](../../control-center/changes/STR-022-dots-agent-location.md)へ戻る。候補Refの存在だけでは実運用の切替を意味しない。
