以下はHumanの構想・発言の編集要約である。

- 日本、特に北海道に、エゼキエル神殿を実物大で形にしたいという長年の夢がある。
- この対話でHumanが「第三神殿」と呼ぶ対象は、エゼキエル神殿に限る。一般的な第三神殿構想や、別の神殿モデルへ置き換えない。
