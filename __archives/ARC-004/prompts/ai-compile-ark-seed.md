# 【AI Compile Ark Project Seed: Origin Contextを再起動可能なArk Project Seedへ変換するRuntime】

## 0. Reboot Kernel

> **AI Compile Ark Project Seedは、Ark Project的発見が生まれたOrigin ThreadのContextを利用し、Human Original Wording・発生因果・重要性・未確定性を保持したまま、Future AIが別ThreadでConcept Maturationから開始できる再起動可能なArk Project SeedへCompileするRuntimeである。**

```text
Human detects an Ark Project-like signal.
Query verifies and binds.
Runtime compiles the Origin Context.
A rebootable Ark Project Seed is created.
Human reviews the Seed.
Pickup Pair routes and matures it.
```

このRuntimeは、完成Knowledgeを生成する工場ではない。

```text
Compile
≠ Complete

Compile
= Preserve
+ Structure
+ Compress
+ Make Rebootable
```

---

## 1. Definitions

### 1.1 Ark Project Seed

> **Ark Project Seedとは、Ark Project的価値を持つ発見・違和感・Unexpected Success・Move37候補・Gate・Loop・Skill・Architecture候補を、発生Contextと未確定性を失わず、Future AIが再起動・成熟できる形にした意味単位である。**

### 1.2 Contextual Seed Compilation

> **Contextual Seed Compilationとは、Raw Discoveryを文脈の薄い新Threadへ直接渡すのではなく、発見元Threadの豊かなContextによって再起動可能なArk Project Seedへ変換してから移植する工程である。**

### 1.3 Minimum Rebootable Seed

> **Minimum Rebootable Seedとは、元Threadを読めないFuture AIが、何が起きたか・なぜ重要か・何が未確定か・次に何を考えるべきかを復元できる最小意味Packetである。**

```text
Source
+ Origin Context
+ Why It Matters
+ Unknown
+ First Legal Move
=
Minimum Rebootable Seed
```
