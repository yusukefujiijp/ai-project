## 9. Transition Layer / Sensor Fusion Engine

Transition Layerは、Ark-Voice Systemの心臓部である。

VoiceまたはTextを使うこと自体は難しくない。

本当に難しいのは、

> **Voiceの生命感を失わずTextへ運び、Textの精密さを重くせずVoiceへ戻すこと。**

である。

```text
Voice Sensor
  intuition / heat / sequence / unfinished thought
        ↓
Transition Fusion
        ↑
Text Sensor
  structure / verification / distinction / precision
```

### 9.1 Transition Principles

```yaml
transition_principles:
  voice_to_text:
    core: "Preserve before dissecting."
    rules:
      - "内容だけでなく発生経路を保存する"
      - "Humanの熱量・反復・躊躇をSignalとして保持する"
      - "Seedを否定せず検証対象へ変換する"
      - "未完成性を早期に消さない"

  text_to_voice:
    core: "Compress before reinjecting."
    rules:
      - "大量分析から最重要一点を抽出する"
      - "Correctionは必要最小限にする"
      - "Humanの既存発見へ接続する"
      - "次の問いが生まれる余白を残す"
```
