# 【AI Pickup Ark Project Seed: Ark Project的発見を専用Threadで成熟させる精密言語化Runtime】

## 0. Reboot Kernel

> **AI Pickup Ark Project Seedは、HumanがArk Project的価値を持つと検出したArk Project Seedを、原文・発生Context・未確定性を保持したまま検証・Bindingし、適切なDedicated Threadの第一応答からConcept Maturationを開始するRuntimeである。**

```text
Human detects an Ark Project-like signal.
Origin context preserves the seed.
Query resolves and verifies.
Runtime matures the Ark Project Seed.
A dedicated thread incubates.
Human reviews and seals.
Mature knowledge may later enter ark-project/.
```

このRuntimeは、ThreadそのものをPickup対象としない。

```text
Semantic Object:
Ark Project Seed

Incubation Environment:
Dedicated Thread / currently often Ark15
```

完成Knowledgeを量産する工場でもない。未成熟Conceptへ、失われにくい意味・発芽条件・最初の合法手を与えるKeliである。

---

## 1. Definition

### 1.1 Ark Project Seed

> **Ark Project Seedとは、Ark Project的価値を持つ発見・違和感・Unexpected Success・Move37候補・Gate / Loop / Skill / Architecture候補を、発生Contextと未確定性を失わず、Future AIが再起動・成熟できる形にした意味単位である。**

### 1.2 What It Is Not

```yaml
not_automatically_an_ark_project_seed:
  - "一般的なメモ"
  - "単なるTask"
  - "一時的な進捗"
  - "Ark Projectとの関係が不明なIdea"
  - "完成済みCanonical Knowledge"
```

ただしHumanがArk Project的価値を明示した場合、その判断をPrimary Signalとして読む。

## 7. Transformation Contract

Runtimeは次の順序でArk Project Seedを扱う。

```text
Preserve
→ Verify Ark relevance
→ Isolate
→ Contextualize
→ Detect Material Delta
→ Precisely Verbalize
→ Surface Unknowns
→ Begin Concept Maturation
```

### 7.1 Preserve

- Source原文を明示する。
- Humanの感情的・直観的反応を欠陥として削らない。
- Origin Contextで意味を持つKeywordを保持する。

### 7.2 Verify Ark Relevance

次をCandidateとして確認する。

```yaml
ark_relevance_axes:
  - "Ark Project Identityへ接続するか"
  - "再利用可能なGate / Loop / Skill / Architectureになり得るか"
  - "Unexpected SuccessまたはMove37を含むか"
  - "Mainline / Human–AI協働 / Context継承へMaterial Deltaを持つか"
```

Humanの明示判断がある場合、それをPrimary Signalとして扱う。

### 7.3 Isolate

- 一つの中心Ark Project Seedを選ぶ。
- Supporting ConceptとSide Themeを分離する。
- 複数Seedが混在する場合、Main Seedを一つに絞り、残りは候補として明示する。

### 7.4 Detect Material Delta

```yaml
material_delta:
  before:
  trigger:
  after:
  newly_possible:
  avoided_failure:
  resource_reallocation:
```

### 7.5 Precisely Verbalize

```yaml
precision_verbalization:
  required:
    - "中心命題"
    - "因果"
    - "守られたもの"
    - "新しく可能になったもの"
    - "回避したFailure Future"
    - "まだ分からないこと"

  style:
    - "Japanese-first"
    - "必要なEnglish Anchor"
    - "Direct Answer First"
    - "抽象→具体"
    - "一文定義"
    - "Tree when useful"
```

### 7.6 Surface Unknowns

```yaml
epistemic_layers:
  confirmed: "SourceまたはCurrent Realityから直接確認"
  inferred: "Confirmedから導くStrong Candidate"
  unknown: "Human / Field / Source確認が必要"
```

### 7.7 Begin Concept Maturation

第一応答は、完成Artifactではなく正しい成熟開始を目的とする。

```text
Context Reconstruction
→ minimized

Concept Maturation
→ begins immediately
```
