# AI Conversation Log Range Analysis (Experimental)

レンジ指定を4パターンを前提にした、AI会話ログ分析の実験用プロンプト骨子。
元投稿（KOBATAKA｜Vibe Modeling(@shion_takk)）の「直近〇〇の期間」という範囲指定の意図を反映し、大量貼り付けを避けつつ認知負荷を下げることを目的とする。

## 使い方
1. 下記プロンプトをコピーする。
2. 【範囲指定パターン】から1つを選び、具体的な範囲を記入する。
3. 選択した範囲に該当する必要最小限のログを【ログ本文】に貼り付ける。
4. 実行し、トークン消費・出力の具体性・自分の感覚とのズレを確認する。

初回はパターン1または4で、ログ量を少なめにすることを推奨。

---

## プロンプト本文

```
あなたは私の過去のAI会話ログを分析するアシスタントです。
以下の範囲指定パターンから1つを選び、指定された範囲のログから項目を抽出してください。

【範囲指定パターン（いずれか1つを選択）】
■ パターン1: 直近短期間
　例：直近3日間 / 直近1週間
　→ 選ぶ場合はここに具体的な範囲を記入：

■ パターン2: 週次区切り
　例：先週分 / 今週の前半
　→ 選ぶ場合はここに具体的な範囲を記入：

■ パターン3: テーマ・プロジェクト絞り込み
　例：〇〇プロジェクトに関連する直近のログ / 特定作業に関するセッション
　→ 選ぶ場合はここに具体的な範囲を記入：

■ パターン4: 最小範囲・ピンポイント
　例：昨日の特定セッション / 直近の特定作業
　→ 選ぶ場合はここに具体的な範囲を記入：

【選択したパターン番号】
（1 / 2 / 3 / 4 のいずれかを記入）

【ログ本文】
（ここに、選択したパターンの範囲に該当する必要最小限のログを貼り付けてください）

【抽出項目】
以下の4項目だけを対象にしてください。
- 不満：私がAIの出力や対応に対して感じていた不満や違和感
- 食い違い：私とAIの間で認識や前提がずれていた箇所
- スキル化候補：セッション中に改善した作業方法や、繰り返し使えそうな手順
- 副次的アイデア：本題とは直接関係ないが、後から価値がありそうな気づきやアイデア

【出力形式】
優先度付きの箇条書きで出力してください。
各項目には「根拠を1行」で簡潔に添えてください。

High:
- （項目内容）根拠: （1行）

Medium:
- （項目内容）根拠: （1行）

Low:
- （項目内容）根拠: （1行）

【指示】
- 簡潔にまとめてください。冗長な説明や繰り返しは避けてください。
- 推測を広げすぎず、ログから読み取れる範囲で記述してください。
- 優先度は「次のセッションで試したいか」「後回しでもよいか」の感覚で判断してください。

【自己評価】
最後に以下を短く述べてください。
- 自信のある点:
- 自信のない点:
```

## メモ
- 実験フェーズ向け。トークン消費量・出力品質・自己の感覚とのズレを確認しながら使う。
- 本格的な自動化やエージェントへの移行は、実験結果を見てから判断する。
