## 新しい成功を読む・残す

再利用したい成功について、当時の対象・環境・Humanの評価と今回の違いを比較する。単発成功、反復成功、長期安定性はそれぞれの証拠で扱う。

Codex固有で独立して残す価値のある新しい成功が得られたら、既存原本との重複を確認し、この本文か共有側を選ぶ。選択・読解・行形式・更新は[共有Success Cases契約](https://github.com/yusukefujiijp/ai-project/blob/main/references/success-cases/README.md)へ。成功への後続訂正や反応を辿れるようにし、GitHub保存だけでHumanの負担軽減や全Threadでの再現を自己認定しない。
