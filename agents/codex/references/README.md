# Codex References

Codexとの協働で生じた反応、条件付きの学び、価値ある成功を、元会話を知らないAIが根拠から読み直す入口。接続・環境確認・再開・説明・成果保存など、Codex固有の経験を扱う。現在の実行条件は[Runtime](../runtime.md)、方法は共有Skill、成果物本文は各専門領域に保つ。

## 経験を選ぶ

| 柱 | ここで扱う意味 | 読む場面 |
|---|---|---|
| [feedback](feedback/README.md) | Codexの説明・判断・操作方法・構成へのHumanの評価、希望、提案、訂正 | 方法を提案する前、違和感や優先順位の変化を受け取った時 |
| [lessons](lessons/README.md) | 接続・環境・協働上の行き詰まりから得た、条件と根拠のある判断 | 同じ問題の再発、別Runtimeへの持込み、成立条件の比較 |
| [success-cases](success-cases/README.md) | Humanが価値を認めた成功の意味、形成過程、成立条件 | 成功した方法を次の機会へ使う時。既存共有事例への接続もこの入口から |

現在の目的から関係する記録を選び、本文・sources・caveatと後続の訂正を読む。今回との共通点と違いを見分け、使う判断・調整する条件・残る未確認へつなげる。Human原文、Human報告、AIの編集・解釈、確認した結果を区別する。

三本は必須の順番でも排他的分類でもない。全件の三重保存や全文同期をせず、必要な意味をIDと出典で結ぶ。同じ根拠の複数参照を独立した実証として数えない。反応を残すだけでもよく、自動的なlesson化待ちTaskにしない。

## 戻す先を選ぶ

| 変わる意味 | 更新する原本 |
|---|---|
| 成果物の事実・表現・根拠 | その成果物と根拠の所有先 |
| Codex固有の反応・再利用判断・成功 | この三本柱の適切な本文 |
| Codexで再開する実行条件 | [runtime.md](../runtime.md) |
| 複数AI・領域に適用する経験・判断 | [共有References](https://github.com/yusukefujiijp/ai-project/blob/main/references/README.md)との分担を確認 |
| 接続など共通方法の改訂 | 対象Skillの原本へ、根拠付きの提案または承認済み変更として接続 |
| 日付から辿る活動／構造変更の理由と検証 | [records](../../../records/README.md)／[STR-025](../../../control-center/changes/STR-025-codex-home-and-reference-pillars.md) |

共通の意味と所有関係は[共有References](https://github.com/yusukefujiijp/ai-project/blob/main/references/README.md)、各形式・読取・更新契約は子READMEからその原本へ進む。局所READMEにはCodex固有の対象・使い方を置き、共通契約を複製しない。保存は[save](https://github.com/yusukefujiijp/ai-project/blob/main/skills/save/SKILL.md)と現在の権限へ接続する。

## 初版の経験と既存原本

初版はこのThreadのHuman発言を用いたFeedbackと、既存の接続実績を根拠とする条件付きlessonを収録する。初期の選択・ID・確認範囲は[STR-025](../../../control-center/changes/STR-025-codex-home-and-reference-pillars.md)へ。局所success-casesは0件で開始し、既存の共有ログイン成功をその入口から参照する。

構成の分かりやすさについては、[共有lesson](https://github.com/yusukefujiijp/ai-project/blob/main/references/lessons/lessons.jsonl)のID `58a39598-788c-465c-823b-1c85c2e50e80`へ戻れる。本文内検索で選び、同じ判断のCodex版を増やさない。記録IDをGitHubの自動アンカーとして扱わない。

この入口の作成と実記録の収録、受け手による発見・理解、実利用効果は別の確認事項。過去の評価・承認は現在の操作指示ではなく、最新の依頼・Correction・STOPと[AGENTS](../../../AGENTS.md)を保持する。
