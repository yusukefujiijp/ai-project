# Codexへの反応と訂正

Codexの提案・説明・接続方法・構成に対して、Humanが何を評価し、何を望み、どこを訂正したかを残す。[本文はfeedback.jsonl](feedback.jsonl)、柱同士の関係と所有先は[親入口](../README.md)が案内する。

## 読む場面

接続の進め方を提案する前、方法の複雑さや待ち時間が問題になった時、構成を変更する時に、関連するtargetと本文・出典・留保・後続訂正を読む。好評価を現在の実行承認や将来の効果実証へ変えない。

## 残す・訂正する

行形式・帰属・原文と編集要約の区別・更新・検証は[共有Feedback契約](https://github.com/yusukefujiijp/ai-project/blob/main/references/feedback/README.md)を参照して適用する。同じ反応の訂正と、後日の新しい反応を分け、対象IDから関係を辿れるようにする。Codex固有の反応をここへ、領域横断の反応を共有側へ残す。

初期記録で用いた原文抜粋の範囲と当時のPlan-onlyは、各行のsources・caveatに保持した。現在の実装承認は別の発言であり、過去の発言を書き換えない。未記録の反応を推測して補わない。
