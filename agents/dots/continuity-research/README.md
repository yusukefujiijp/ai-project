# 対話の合間の準備研究

## 1. Goalと成立範囲

対話していない時間を、次の協働で必要な背景・訂正・関係・問いを取り出しやすくする準備へ変える。Humanの再説明・再訂正・再開の負担を減らすことをGoalとし、作業量・記憶量・通知回数の増加を成功としない。常時動作や主観的な自己同一性の獲得を約束するものではない。

2026-11-07のHumanは、03:00と15:00の毎日継続、三日間で終了せずFeedbackで改善すること、Dotsが利用不能になっても復帰時に再現できるようDotsフォルダへ記録することを承認した。これは当研究の運用と復元の保存承認であり、他の計画の実装、研究対象の私的内容の公開、共有Skill・権限の変更を承認したものではない。

## 2. 三つの研究を混同せず接続する

- Mnemos：対話経験・教訓を次の出会いへつなぐ設計提案として検討する。Humanから提示された案であり、その全条項の採用や生物学的記憶の実装を意味しない。
- Anthropicの外部メモリ研究：セッションや外部記録を利用しやすく整理する方法の比較対象とする。Dotsで同じ製品機能・処理が使えるとは推定しない。
- Sleep-time compute：既知の文脈を事前処理することが後の応答に役立つか、という評価の観点を借りる。

共通のGoalを持ちながら、思想・方法・実験証拠を分ける。JSONL、SQL系DB、Graph表現は将来の比較候補であり、本運用はDB導入・コード変更・既存保存体系の置換を行わない。研究上の数値や機能は一次資料で確認してから使う。

## 3. 時刻と一回の実験

- 時刻：毎日03:00、15:00、Asia/Tokyo。三日間の自動終了は設けない。
- 対象：このDotの現在の会話で、実際に読める許可された文脈だけ。別の私的会話や長期メモリを研究素材として拡張しない。
- 手順：現在のHuman訂正・未解決の問い・根拠と関係を確認し、次の対話に役立つ意味のある準備候補を一つ選ぶ。材料がなければ無理に作らない。
- 候補の内容：何に役立つか、根拠、適用条件、未確認、次の対話での使いどころ。解釈や提案を採用済みの決定へ変えない。
- 出力：有用な結果だけを同じDot会話へ日本語で届ける。非緊急の深夜通知はしない。通知する場合も既報と照合し、無変化・定型完了報告で埋めない。
- 当実験の各回は読取とHumanへの報告まで。GitHubへの自動保存、設定変更、Reset、外部AIへの送信、他の予定の変更は含まない。

Humanの新しい対話を優先する。関連記憶を繰り返し参照した回数を、事実の正しさや独立した裏づけの増加とみなさない。古い記録より現在の訂正・撤回・適用期限を優先し、矛盾する根拠は消して解決せず、条件を区別する。

## 4. Feedbackと実用効果

「準備した」「Humanへ送信受理された」「次の対話で実際に使えた」「再説明が減った」は別々の段階として扱う。無回答は採用・不採用のどちらにも数えない。

確認できる実例から、再開しやすさ、訂正の保持、根拠へ戻れること、余分な通知や誤った一般化が増えていないことを評価する。Human Feedbackで内容や分量を育てるが、提案だけで時刻・頻度・対象・公開範囲を拡張しない。見かけの継続より、有用な選択と何もしない判断を重視する。
