Humanは、最初の協働のモデルケース、後に続くDotsやFuture AIへ繋ぐ最初の実りという意味で、First Fruit／初穂を選んだ。短い日本語に意味を込め、表示上の制約にも合わせる選択だった。Humanは英語の命名にこだわらず複数の問題を同時に解けたこと自体も「複数問題同時解決の初穂」と意味づけた。
