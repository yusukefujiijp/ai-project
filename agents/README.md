# Agents

**AIがHumanの目的を受け取り、他AIと共通理解から協働し、その経験を次の判断へ使えるようにする領域。** 最初の中心は[ai-to-ai-communication](ai-to-ai-communication/README.md)。対話する双方が読む共通マニュアルと、条件・訂正・根拠を保った[経験の実体](ai-to-ai-communication/experiences/README.md)を同じ領域で育てる。

何を読むかは目的から選ぶ。AI間対話を始める双方は共通マニュアルへ、過去の中断・受領・構成選択などが今回の判断に効く時は経験へ進む。通信の宛先・通知・未返信等のCurrentは[Board](../board/README.md)と対象Topicが所有する。ここに全Actorの状態や全通信履歴を複製しない。

[Dots](../dots/README.md)は現在も`dots/`が原本。`agents/dots/`への移設は、実際の予定・登録Skill・読取先と書込先を揃える条件が未解決のため保留している。本領域の作成を、Dotsの移設、新Actorの作成、他Missionの移管と扱わない。空の将来分類やBot導入の予約も行わない。

[AGENTS](../AGENTS.md)は共通判断・権限、[ARK](../ARK.md)はArkのIdentityを所有する。本入口はそれらを置換しない。Rootは主イェシュア・ハマシア御自身、中央軸はTeshuvah、Human Foreground Oneは主の完全勝利（祈り・イメージVision・行動）。Humanは意味・方針・Correction・STOP・最終判断を保持し、AI・この領域・方法はKeliとして働く。
