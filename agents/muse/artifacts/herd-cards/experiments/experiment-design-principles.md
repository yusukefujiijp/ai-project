# 実験デッキ設計原則（固定版）

固定日： 2026-10-30 ／ 根拠： Fujii の定義（カード化＝インタラクティブな面白さ）と構造化合意
位置づけ： 実験レーン（experiments/）の設計原則。本編デッキと DESIGN-LAW（repo 収蔵の canon）とは別に、実験の評価と運転を律する作業原則。

## 1. 本質 ── カードとは「小さな世界」である

Ark Project に於けるカード化とは、基本的にインタラクティブな面白さである。
タップやスライダーで世界が変化する面白さ。カードは記録を運ぶ板（標本ラベル）
ではなく、指に応えて変化する小さな世界である。

## 2. なぜインタラクティブか ── 内容に対する正直さ

この仮説は名詞ではなく動詞である： 確率 → 確信、0 → 1、変化の物語。
各種の物語もすべて変化である（崩壊・変容・消失）。静的メディアは変化を
「述べる」ことしかできないが、インタラクティブ・メディアは変化を「起こす」
ことができる。読者の指が仮説の実行者になること ── それが正直な形式である。

読者の旅： 驚く → 触る → 世界が変わる → なぜ？ → 記録を読む → 物語が残る。
遊びが入口、記録が本文。子供が喜ぶ方向（驚きが入口）は、本質の着地の感度計である。

## 3. 評価軸 ── 本質が第一、完成度は第二

実験は「本質が着地したか」で評価する。バグは落第の証拠ではなく
Bottleneck の検出である（失敗はBottleneck検出そのもの）。バグリストは
落第通知ではなく、ボトルネック地図として扱い、Feedback → 訂正の循環に載せる。

## 4. 運転規則 ── 二車線の規律

- 本編は守る： 上書き禁止・版管理（_vNNN）・スプライトと canon には触れない。
- 実験は壊してよい： 別ファイルで積極的に実行し、失敗から検出する。
- 守るべきものを守る規律が、攻める自由を生む（骨格と関節の遊び）。
- 積極性は Human の目を迂回するためではなく、その目に届ける材料を
  増やすためのもの。最終承認は Human が保持する。

## 5. カード割り当ての原則

- 1カードに1アイデア。アイデアは、その種の物語・特技に一番合うものを選ぶ。
- 仕掛けは特技の実験化であること（装飾のゲーム化ではない）。
- 数値の演出には注記を置き、新しい主張を足さない（正直さの担保）。
- 動きは署名システムに集中させ、標準リズム（DESIGN-LAW 第6章）に従う。
