# experiments/ ── 実験レーン

このフォルダは、群れカードの**実験レーン**である ── 「1カード×1アイデア」を全部入りの一枚にした実験デッキと、その設計文書の置き場。本編（収蔵デッキ）とは別に、壊してよい場所として開かれた（2026-10-30）。

## 中身

- `experiment-design-principles.md` ── 実験の設計原則。
- `experiment-deck-v001-bottleneck-map.md` ── Bottleneck 地図（実験デッキ v001 の記録文書。デッキ本体の v001 は収蔵されていない）。
- `herd-cards-experiments_v002.html` 〜 `herd-cards-experiments_v022.html` ── 実験デッキの版列（19版）。欠番は v001・v016・v018 ── v016 は実測で不採用、v018 はボタンラベルの一字誤りを検証で検出して不採用。いずれも収蔵していない。

## 現在地

- 最新は **v022**（LP 実験版）。**v021** が非 LP の戻り先である。LP 実験が良い方向か悪い方向かの判定は、YusukeJP の実機の目による（Herd LANE の事項）。

## 所有へのポインタ

- 設計法則の原本 ── [../../../DESIGN-LAW.md](../../../DESIGN-LAW.md)。
