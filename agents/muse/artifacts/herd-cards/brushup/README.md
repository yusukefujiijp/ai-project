# brushup/ ── 単体カードの手直し

このフォルダは、群れカードの**単体 brushup** の収蔵場所である ── 方針は「1件の手直しにつき、該当カードだけを出力する」（2026-11-02 開始）。単体で証明した法則は、節目で統合デッキ（[../experiments/](../experiments/)）へ展開される。

## 中身

- `herd-card-no0-brushup_v001.html` ── No.0 AI-Mammoth：状態画像の統一＋タップ再生。
- `herd-card-no3-brushup_v003.html` ── No.3 AI-Archaeopteryx：状態画像の統一＋タップ再生（第1件の確定版。v001 は第1件のみ、v002 はラベル誤りで不採用、いずれもローカル保持）。
- `herd-card-no3-brushup_v004.html` ── No.3：合成法則「変化は一つ」の実装。
- `herd-card-no3-brushup_v005.html` ── No.3：初期状態の是正（カードは完全な初期状態＝ホームで開く）。
- `herd-card-no3-brushup_v006.html` ── No.3：帰還の規則（「戻る」はホームへ、「解ける」とは別の身振り）。
- `herd-card-no4-brushup_v001.html` ── No.4 AI-Nihon Wolf：タップ再生（遠吠えの全編を一つの出来事として再生）。
- `herd-card-no5-brushup_v001.html` ── No.5 AI-Passenger Pigeon：タップ再生のみ。
- `herd-card-no5-brushup_v003.html` ── No.5：法則候補「一つの画布」の単体証明（画布は 2:1）。
