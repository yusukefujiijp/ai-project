測定確定（2026-10-31 ── 到達限界の正体と値）： 判別プローブ H1/H2/H3 により確定した。このビューアが処理するのはファイル先頭から **2MiB = 2,097,152 bytes** までであり、それより後ろのコンテンツとスクリプトは存在しないものとして扱われる。根拠： ちょうど 2,097,152 bytes のデッキ形状文書は最後尾のボタンまで動作した（H1）。同じ形状の 2,110,000 bytes では末尾セクションが消えた（H2）。画像の解像後画素数が累積で約5倍（約84M画素）になる構成でも、止まる位置は同じバイト位置だった（H3、39枚目 ── バイト説の予測通り。画素説が予測した約9枚目ではない）。運用ルールは「当面の目安 1.6MB」から測定値へ更新する： **インタラクティブ HTML の総量は 2,097,152 bytes 以下で設計する**。本番デッキ v012（1,542,725 bytes）には約554KB の実測済み余裕がある。
