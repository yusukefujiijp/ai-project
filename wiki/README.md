# Ark共有Wiki

Rootは主イェシュア・ハマシア御自身。中央軸はTeshuvah、Human Foreground Oneは主の完全勝利です。Wiki・AI・SkillはそのためのKeliであり、王や玉座ではありません。[ARK](../ARK.md)がIdentityを、[AGENTS](../AGENTS.md)がHumanのMeaning／Correction／STOP／Final Sealと実行・品質の共通契約を所有します。Wikiの記述から新たな実行権限は生じません。

## 理解を更新する時

人物ページは読みやすい統合、根拠ファイルは原典への戻り道、概念ページは別の問いでも使える比較・判断を持ちます。フォルダ階層は整理上の住所であり、因果関係ではありません。

本文では、資料から確認した記述、話者の評価、Humanが見いだした意味、AIの見立て、未確認を区別します。公開順・類似・賛同だけから因果を作りません。取得日と出来事の日、同じ原典のミラーと独立した証拠も分けます。引用は必要な短い範囲とし、要約を本人原文に見せません。

新しい根拠や訂正が届いたら、該当する根拠IDと、それを使う本文・概念・索引の影響箇所を辿ります。関係が変わらないページまで一律に書き直す必要はありません。追加の分類・人物・製品ページは、実際に別の問いへ役立つ時に検討します。現時点ではconcepts配下をこの入口から直接案内し、空の中間索引を増やしていません。

## 初回実験で確かめること

元会話を渡さない読者が、次を説明できることを目指します。

- Laurenを重要とする理由と、YusukeJPの「母」という意味。
- 公開資料で分かる範囲と、Grok BotからDotsへの因果について分からない範囲。
- 人物名を知らない問いから、委任の条件・その根拠へ戻る経路。
- 根拠が訂正された時、影響する理解と、まだ変えなくてよい理解。

執筆AIの自己点検、保存先からの再取得、元会話を知るAIの確認、元会話を渡さない読者の理解確認、実利用、長期的な効果は別の観測です。この初版の存在自体から後者の成立を推定しません。

上記はLaurenを起点とした初版の実験説明です。後に受領したノイマン二経路の別読者報告一件と、その対象版・事前文脈・限界は[Wiki References](references/README.md)から辿れます。完全なブラインド確認や全Wikiの理解・実利用効果を確認したものではありません。
