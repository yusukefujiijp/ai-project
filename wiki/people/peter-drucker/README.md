<a id="pd-person"></a>
## 1. 人物の共通土台

ピーター・F・ドラッカー（Peter F. Drucker、1909–2005）は、ウィーンに生まれた経営思想家、著述家、教育者、コンサルタントです。企業だけでなく、非営利・公共組織にも関わりました。Drucker Instituteの人物紹介は、責任ある組織と機能する社会への関心を、その仕事の背景に位置づけています。［[E-PD-PERSON](evidence.jsonl)］

本研究では、経験を既存の見方に押し込めず、判断を更新する手掛かりとして読む点に注目します。これは今回の研究上の着眼点であり、人物の全体定義ではありません。「予期せぬ成功」の最初の提唱者であるという歴史的な優先権は、今回確認していません。

<a id="pd-unexpected"></a>
## 3. 本人の説明と、読んだ範囲

『Innovation and Entrepreneurship: Practice and Principles』は1985年刊の著作です。今回読んだ第3章I「THE UNEXPECTED SUCCESS」は、従来の見方に合わない成功の見落としと、そこから機会を探り、活用する方向や必要な体制を判断することを扱います。直接の文脈は組織の革新・起業家活動です。［[E-PD-INNOVATION](evidence.jsonl)］

Drucker Instituteの2018年の翻案資料では、予期せぬ成功・失敗が、革新機会を探す七領域の一つに位置づけられています。この七領域は、ノイマン研究で引き継いだ動画の七項目とは別です。翻案資料を1985年原文そのものとしては扱いません。［[E-PD-SOURCES](evidence.jsonl)］

本文読解には、第三者サイト掲載の電子版を用いました。第3章Iは全文を読みましたが、著作全体は未読です。奥付は2002年11月の電子版で、URLのファイル名にある2006を版年に採用していません。2015年版の出版社系試読で書誌と章構成も確認しましたが、同版全文との逐語照合はしていません。

<a id="pd-application"></a>
## 4. Arkへの適用条件と、AIの生きた意見

以下は、原典・Humanの関心・既存ノイマンWikiから考えたAIの候補です。ドラッカー本人のArk向け指示でも、実利用で効果を確認した方法でもありません。［[E-PD-INNOVATION](evidence.jsonl)・[E-PD-HUMAN](evidence.jsonl)・[E-PD-JVN](evidence.jsonl)］

**第一に、「何が良かったか」と「何が予想外だったか」を分けて残すと、意味を失いにくいと考えます。** Humanの好結果の報告はそのまま受け取れます。そのうえで予期せぬ成功として検討するなら、誰のどの期待と違ったかを、分かる範囲で確かめます。事前の期待が不明なら、不明のまま保持します。AIが後から予測を作って、すべての好結果を予期せぬ成功に分類する必要はありません。

**第二に、経験を受け取ること、原因を考えること、方法を採用・拡大することには、異なる判断が必要です。** 原因不明でも、価値ある経験を残せます。一方、別の仕事へ広げる判断では、目的、成立条件、必要な支援、負担、取り消せる範囲を見ます。成功を喜んだHumanへ、新しい検証Taskを自動的に課すことはしません。

**第三に、方法の改善だけでなく、最初の問いや比較条件を見直す余地が重要です。** 意外な好結果から別の価値が見えた時、AIはその解釈と代案を示せます。ただし、新しい価値の採否や優先順位を、Humanに代わって確定しません。

今回の仮想比較では、既存の評価条件のもとで成果が予想を上回る場合と、別の価値が見えて評価観点を見直す場合を分けて考えました。両者は同じ出来事に重なり得る見方であり、ドラッカー本人による二分類ではありません。

新しい価値を受け取っても、当初の目的・評価条件・達成状況は上書きしません。何が達成され、何が未決で、何を新しく見いだしたかを分けます。評価観点の見直しには、既存の意味の言語化、優先順位の変更、新しい目標の追加があり、同じ変更として扱いません。Humanの明示的なCorrectionは反映し、有効な委任内の言語化・比較を続け、新たな実行だけをその承認範囲に照合します。

これは仮想比較から得たAIの適用案です。Humanの実体験、原因の実証、実利用効果を示すものではありません。

| 判断する場面 | AIが担えること | 保持する条件・限界 |
|---|---|---|
| 好結果を受け取る | 誰の報告か、何が良かったかを言語化する | 原因の説明がないことを理由に経験を捨てない |
| 「予期せぬ」を確かめる | 確認できる従来の期待と結果を比較する | Humanの驚きの報告と、事前記録による比較を区別する |
| 他の場面へ使うか考える | 複数の原因仮説、適用条件、反例を比較する | 仮説を実証へ格上げせず、不要な調査を一律に課さない |
| 新しい仕事を始める・広げる | 現在の委任内で進められる部分を遂行し、新しい判断だけを分ける | 好評価から追加権限を作らない。保留を理由に既存の委任まで止めない |

この節は、現行の[委任と信頼](../../concepts/agent-trust/README.md)や[ノイマンの適用節](../john-von-neumann/README.md#jvn-application)に接続する候補です。今回、その原本を改訂したわけではありません。

## 5. ノイマン研究との関係

比較するのは、両人物の全業績ではなく、今回のWikiが取り出した着眼点です。［[E-PD-JVN](evidence.jsonl)・[E-PD-INNOVATION](evidence.jsonl)］

| 着眼点 | 接続して考えられること | 混同しないこと |
|---|---|---|
| ノイマンWiki：問い・比較条件・モデルの前提を明らかにする | 結果を何と比べ、どの範囲で判断するか | 七項目・五核・四視点を本人の確定した教えにしない |
| ドラッカー研究：従来の見方に収まらない好結果を読む | 比較の前提そのものを変える必要があるか | 個人の経験への転用を本人の原文や実証と同一視しない |
| AIによる補完案：条件を明らかにしつつ、条件の見直しにも開いておく | 経験を残し、必要な時に理由へ戻って判断を更新する | ノイマンからドラッカーへの歴史的影響や、万能な循環モデルを主張しない |

ノイマンWikiの成功報告・原因仮説・再利用条件の区別は再利用します。そこへ「誰にとって、何が予期せぬことだったか」という問いを加えることが、今回のAIによる提案です。新しい必須記入欄や計算式ではありません。

<a id="pd-unknowns"></a>
## 6. 重要なUnknownと、見直す条件

- 著作全体の読解、使用した転載本文と同版の出版社配信全文との一致は未確認です。
- 本文中の企業等の事例を、独立した史実検証や効果測定として確認したものではありません。
- ノイマンからドラッカーへの直接的な影響関係、「予期せぬ成功」の歴史的な初出は未確認です。
- Arkの具体的な経験への適合性、今回の草案の別読者による理解、実利用・長期効果は未確認です。

新しい原典、HumanのCorrection、適用した時の反例によって判断が変わる場合に、関係する説明を見直します。Unknownがあることだけを理由に、既存の経験や独立して進められる仕事を無効にしません。

## 7. 根拠と訂正の読み方

[根拠記録](evidence.jsonl)でIDを検索し、claims.ref・relation・scopeを合わせて読みます。ID専用アンカーは作っていません。supportsは記載した範囲を支える関係、informsは解釈や適用を考える材料になる関係です。

acquisitionsは、この草案を作成したAIによる取得・読解記録です。後の閲覧者自身が原典を再確認したことを表しません。取得日、著作の刊行年、転載版の奥付、Humanの発言日は分けます。

| 訂正された根拠 | 見直す説明 | 直ちには変わらない説明 |
|---|---|---|
| E-PD-PERSON | §1の訂正に関係する人物情報 | 別の原典で支える§3やHumanの意味 |
| E-PD-INNOVATION | §3の該当要約と、それに依存する§4・§5の見立て | HumanがKeywordとして重視したという報告 |
| E-PD-SOURCES | §3の翻案資料・七領域についての説明 | 著作本文から別に確認した記述 |
| E-PD-HUMAN | §2と、その意味を材料にする§4の該当範囲 | ドラッカーの書誌・著作本文 |
| E-PD-JVN | §4の継承した区別、§5の比較 | ドラッカー自身の議論 |

informsの材料が訂正されても、AIの見立て全体が自動的に偽になるわけではありません。失われた理由と残る理由を確認します。同じ著作に由来する転載と翻案も、独立した効果実証には数えません。
