## 1. 十二人の代表者

民13:4–15の順序を保つ。日本語転写の違いを補うため英語名を併記する。名簿の全員が、派遣時にはそれぞれの部族の指導者として紹介される。

| 部族 | 人物 | 父 |
|---|---|---|
| ルベン | シャンムア Shammua | ザクル Zaccur |
| シメオン | シャファト Shaphat | ホリ Hori |
| ユダ | カレブ Caleb | エフネ Jephunneh |
| イッサカル | イグアル Igal | ヨセフ Joseph |
| エフライム | ホシェア Hoshea（13:16でヨシュア） | ヌン Nun |
| ベニヤミン | パルティ Palti | ラフ Raphu / Rafu |
| ゼブルン | ガディエル Gaddiel | ソディ Sodi |
| ヨセフのうちマナセ | ガディ Gaddi | スシ Susi |
| ダン | アミエル Ammiel | ゲマリ Gemalli |
| アシェル | セトル Sethur | ミカエル Michael |
| ナフタリ | ナフビ Nahbi | ヴォフシ Vophsi |
| ガド | ゲウエル Geuel | マキ Machi |

「十二部族」はこの名簿の編成である。レビを追加して十三人にしたり、ヨセフをエフライム・マナセと重複して数えたりしない。民14:36–38の結末から、カレブとヨシュアを除く十人を否定的報告者として区別する。

<a id="mission"></a>
## 2. 調べるべきものは軍事力だけではなかった

モーセの質問（13:17–20）は、土地の良否、人々の強弱と数、都市の開放性／城壁、土壌、木の有無に及ぶ。果実を持ち帰る指示もあり、葡萄の初熟の季節だと説明される。土地の豊かさは調査の正式な対象である。

ネゲブから山地へ進むよう命じられ、旅程の概略はツィンの荒野からレホブ／レボ・ハマトまでとされる。ヘブロンではアナク人のアヒマン、シェシャイ、タルマイが名指される。エシュコルの谷では葡萄の房とザクロ、いちじくを採る。13:23の通常の読みでは房を二人で棒に載せて運ぶ。人数・棒を増やす読みは[Sotahの再話](talmud-sotah.md#grapes)で扱う。

帰還は四十日後、パランの荒野のカデシュ。13:27–29の報告は、乳と蜜、果実、強大な住民、大きな城壁都市、複数の住民集団を併せて述べる。危険を報告する行為そのものが、ただちに中傷なのではない。

<a id="report"></a>
## 3. 観察から「不可能」へ移る接点

カレブは13:30で民を静め、上って取得できると発言する。ほかの者は13:31で「上れない」と応じる。その後の語り手は、土地についての報告を悪評／中傷として紹介する（13:32）。土地が住民を食い尽くす、全員が大きい、ネフィリムがいる、自分たちはばったのようだ、と報告が展開する。

ここには三種類の内容が重なる。

- 目にした対象についての報告：都市、果実、人々。
- 能力と未来についての判断：自分たちは上れない。
- 自他の見え方についての主張：自分たちにも、相手にも、ばったのように見えた。

第三の点を単なる心理学の用語で説明し切らない。Sotah 35aには「相手の目をどう知ったのか」という問いと、声を聞いたという反論が両方ある。一方、Tanhuma Buber §11は、相手にどう見えたかを決めつけることを問い返す。[伝承間の違い](rabbinic-readings.md#differences)

<a id="future"></a>
## 4. 報告は世代の未来へ波及する

民は夜に泣き、エジプトへの帰還を求める。モーセとアロンがひれ伏し、ヨシュアとカレブが衣を裂いて共同体へ語る（14:5–9）。彼らは土地の良さを強調し、反逆せず恐れないよう訴える。しかし石打ちの脅威が続く。**聴衆を静かにできたという場面を、共同体の採用・実行の成立に読み替えない。**

モーセの執り成しの後、四十日の偵察と対応する四十年が語られる（14:34）。裁きの対象の説明には、二十歳以上の数えられた者たちという範囲がある（14:29）。「出エジプトした全員が二人以外一律に死んだ」と、女性、子ども、人口調査の範囲を消す要約にはしない。民26:63–65も、二つの人口調査を比較して読む。

子どもたちは将来の入地を約束される。十人は疫病で死に、二人が残る。結末の無断出陣と敗北まで含めることで、この事件は「積極的な人が勝つ」という単線の教訓を超える。
