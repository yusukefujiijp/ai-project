# Tanhuma Buber — 変わる斥候、介入するカレブ

[入口](README.md) / [文献比較](rabbinic-readings.md) / [版と原典R2](sources.md#r2)

目次： [文献](#edition)・[人間化](#change)・[介入](#intervention)・[中傷と慈悲](#mercy)

<a id="edition"></a>
## 1. 今回読んだ範囲

対象は **Midrash Tanchuma Buber, Sh'lach §§1–25**。Sefaria上のBuber 1885ヘブライ語本文とTownsend英訳を用い、§§5,11,15,19はヘブライ語も重点照合した。通常版Tanhumaの節番号とは区別する。Supplement、Va-Etchanan、Numbers Rabbahの全文校合は今回の実施範囲に含めない。

§1は安息日前の航海と宗教的使命を問う導入から、ヨシュアが送った二人をピネハスとカレブとする伝承へ進む。ヨシュア記2章自体では二人は無名である。使者の成功と失敗を比較する説教の枠組みとして読む。

<a id="change"></a>
## 2. 斥候たちは、最初から固定された悪人ではない

§5は、彼らがイスラエルとモーセの目に正しく、個々の派遣について神の承認も得たと述べる。そして四十日の後に変わり、世代へ災いをもたらしたと説明する。§11はアナク人を見て恐れたと語る。

ここでは「正しい者として選ばれた過去」と「悪い報告に至った現在」が同居する。失敗を元からの本性の露呈だけで説明せず、任務の中で変化する人間として読む足場がある。ただし、現代心理学的な恐怖の因果を測定した記述ではない。

§11の末尾には、肉なる使者と将来の天使を対照させる希望がある。「斥候各人の個別の救済経歴を確定した」とまで拡大せず、文献が罰だけで展望を閉じないことを捉える。

<a id="intervention"></a>
## 3. カレブの英雄化には、強制的な場面もある

§2はモーセとアロンが報告に対処できない場面にカレブの行動を置く。これはその説教の対比であり、Torah全体のモーセを無力と評価する結論ではない。

§19では、カレブは同じ意見のように振る舞うが心では真実を語ろうとしていたと説明される。台に立ち、人々が批判を聞けると思って静まった時、「上って行こう」と語る。しかし直後に反論が起こる。**一時的な発言権の獲得は、反対者の消失ではない。**

§15の果実の場面はさらに強い。仲間が持ち帰ろうとしないため、カレブは武器を抜き、互いの命に関わる威嚇をする。単に「丁寧に説得した」と要約すると、原典が描く英雄化の性格を変えてしまう。果実を持ち帰らせたことと相続の報いが結びつけられるが、脅しを現代の協働の推奨法へ変換しない。

§15には棒の数と重量についての複数説もある。Sotahの八人の図を、そのままこの節の唯一の構図として貼り付けない。

<a id="mercy"></a>
## 4. 土地、中傷、モーセの執り成し

§6は、斥候事件がミリアムの記事の後に置かれた理由を、中傷の結果から学ぶべきだったことに求める。§17は良いことから始めて悪いことへ終わる語りを指摘する。§18はアマレクという名が、過去の恐怖を呼び起こす働きを説明する。記憶は希望へも恐怖へも動員され得る。

§3は、祖先が死んでも神の約束は失われないとする譬えを置く。§7は民の不信を、父が選んだ花嫁を信じない息子に譬える。§8はモーセの相談と人間側の裁量を描く。これらを、誰か一人だけの責任を確定する説明へ統一しない。

§24ではモーセが祖先との契約、諸国の受け取り方を持ち出し、慈悲が裁きを上回るよう願う。赦しの応答と、入地しない世代の罰（§25）は並存する。未来への希望を語ることは、現在の責任や結果を消すことではない。
