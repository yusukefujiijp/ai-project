# Torahにおけるカレブ — 民数記と申命記を読む

[入口](README.md) / [斥候事件の詳細](twelve-spies.md) / [出典](sources.md)

目次： [語りの違い](#retellings)・[評価の言葉](#spirit)・[責任と共同体](#responsibility)

<a id="retellings"></a>
## 1. 同じ事件を、異なる語りの中で読む

民数記13–14章は派遣、現地、報告、反応、裁き、誤った再出発を場面として進める。申命記1:19–46では、モーセが次の世代へ過去を語り直す。後者は単なる省略版ではなく、聴衆の責任と土地へ進む時の信頼を前景化する。[B1・B2](sources.md#b1)

| 比較点 | 民数記13–14章 | 申命記1:19–46 |
|---|---|---|
| 派遣の開始 | 《創造主》がモーセに派遣を告げ、命に従って送る（13:1–3） | 民が経路と都市の調査を提案し、モーセが良いと思って選ぶ（1:22–23） |
| 任務 | 人口・強さ・土地・都市・木・果実（13:17–20） | 行く道と入る都市について報告する（1:22） |
| 報告 | 良い土地の確認から、不能判断・悪評へ展開 | まず「良い土地」（1:25）。その後、民が兄弟の報告を恐怖の理由として語る（1:28） |
| カレブ | 最初の単独反論、共同発言、名指しの評価 | 土地に入る例外と相続を受ける者（1:36） |
| ヨシュア | 改名、カレブと衣を裂き語る、例外として生存 | モーセの後を継ぎ、イスラエルに相続させる者（1:38） |
| モーセ | 派遣、執り成し、勝手な出陣への制止 | 過去を語る当事者。「あなたがたのために」自分も入れないと述べる（1:37） |
| 結末 | 命令に逆らう出陣と敗北（14:39–45） | 同様の出陣、敗北、応答されない嘆き（1:41–46） |

ラビ文献は「あなたのために送れ」を裁量・許可として読み、民の要求、モーセの判断、神の命令の関係を説明する。**この調和的な解釈を、民数記単独の字義と同じにしない。** また申1:37を、民20:12や申32:51のメリバの説明へ無言で置換しない。今回は最終形の物語比較を行い、各段落の成立年代・資料層の確定は行っていない。

<a id="spirit"></a>
## 2. 「別の霊」と「従い通した」

民14:24は、カレブを「わたしの僕」と呼び、רוּחַ אַחֶרֶת（ruaḥ aḥeret、別の霊）が共にあり、「わたしに従い通した」と評価する。ここでの「別」は、反抗する共同体との対照の中で読む。独自の人格類型や、一般的な超能力の名称を本文から作らない。

「従い通す」に関わる מִלֵּא אַחֲרֵי（milleʾ aḥarei）は、後について行くことを全うする表現である。民14:24では神の評価、ヨシュ14:8ではカレブの自己証言、14:9では回想されたモーセの誓い、14:14では語り手の説明に現れる。話者が変わること自体が、長い時間をつなぐ構成を作る。[八十五歳の読解](caleb-at-85.md#voices)

<a id="responsibility"></a>
## 3. 恐怖の否定だけでは読めない

民14:3の民は妻子が奪われることを恐れる。恐怖には具体的な対象がある。しかし裁きの場面では、奪われるとされた子どもたちが土地へ入る者になる（14:31）。物語は、未来を守るつもりの判断が、どの未来を閉じたかを反転させる。

さらに14:39–45では、人々が進む気持ちになっても、モーセは止める。したがって「恐れず進め」だけを永続的な命令として切り取れない。本文が評価するのは、現在の命令と伴いへの応答を含む忠実さである。これは、現在の条件を見ずに昔の決意を反復することとの違いを考える足場になる。

モーセは14:13–19でエジプトと諸国から見た神の名誉、約束、慈悲を訴える。「赦した」という応答と、荒野で世代が交代する裁きは同じ章に残る。慈悲を無結果・無責任へ置換しない。[Seder Eliyahu](seder-eliyahu.md)は、この緊張を別の角度から展開する。
