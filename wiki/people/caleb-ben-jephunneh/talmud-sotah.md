# Sotah 34a–35a — 祈る者、語る者、土地の読者

[入口](README.md) / [比較](rabbinic-readings.md) / [原典と版R1](sources.md#r1)

目次： [葡萄](#grapes)・[派遣](#sending)・[祈り](#prayer)・[発言](#speech)・[報告](#testimony)

<a id="grapes"></a>
## 1. 石から葡萄へ

34aはヨルダンを渡る場面と、そこから運ぶ石の重さを論じる。その運搬能力から、民13:23の葡萄の房へ話が移る。直前の議論を知ると、巨大な葡萄が突然挿入された余談ではないことが分かる。

34a:9では「棒」「二つ」を問い、棒を増やして読む。34a:10のラビ・イツハクの説明では、葡萄を八人、ザクロを一人、いちじくを一人が運び、ヨシュアとカレブは何も運ばない。理由は、二人が重要な人物だからという説明と、斥候の悪い助言に加わらなかったからという説明の二つがある。後者では果実が恐怖を与える材料として用いられる。

民数記の二人による運搬と、この増幅を混同しない。重量の議論から現代単位への正確な換算や、実在した房の質量を導くこともできない。

<a id="sending"></a>
## 2. 誰の判断で送ったのか

34b:3は「あなたのために送れ」をモーセの裁量として読み、申1:23の「私の目に良かった」と結ぶ。34b:4は探索を表す語と恥を表す語を結び、土地を辱める意図を読む。35a:1も出発と帰還を同じ悪い助言で結ぶ。

34b:5–6ではセトル／ミカエル、ナフビ／ヴォフシの名が行為を表すものとして解釈される。これは物語上の語釈であり、十二人全員の確定した語源一覧ではない。ヨシュアの改名は、悪い助言から救われるようにというモーセの祈りとして読まれる。

<a id="prayer"></a>
## 3. カレブは、助けを求める

34b:7は、民13:22の単数形を足場に、カレブがヘブロンの族長の墓へ行く場面を描く。彼は斥候の助言から救われるよう、族長たちに慈悲を求める祈りの執り成しを頼む。34b:8はヨシュアには既にモーセの祈りがあると説明する。

この描写は、孤立しても自力で正しさを保ったというだけの英雄像を修正する。共同体の圧力にさらされる者が、自分を守る関係へ向かう。土地はその祈りが起こる祖先の場所として現れる。[ヘブロン](hebron-and-ancestral-memory.md)

34b:11–13のヘブロンとツォアンの比較は、石の多い土地と豊かさ、牧畜と耕作を論じる。七年を七倍の豊かさへ読むのは、土地への評価を形作る釈義である。

<a id="speech"></a>
## 4. カレブが得たのは、まず発言の機会である

35a:3–6では、ヨシュアは群衆に遮られる。カレブは自分も遮られると考え、モーセへの批判と受け取られそうな問いで話し始める。静まった人々へ、出エジプト、海が分かれたこと、マナを与えられたことを想起させ、進むよう促す。

「梯子を作って天へ上れと言われても」という表現は、物語内の強い信頼を示す修辞であり、実行手順ではない。共有記憶は、目の前の恐怖だけで結論を閉じないための根拠として働く。ただし直後の35a:7では反論が続く。局面での沈黙・傾聴と、共同体全体の決断の変化を分ける。

<a id="testimony"></a>
## 5. 真実を含む報告と、解釈の誤り

35a:2は、最初に真実を含む中傷が受け入れられやすいと説明する。35a:8は、住民の死と弔いを、斥候が発見されないための配慮として描く。斥候はそれを「住民を食い尽くす土地」と読む。別説ではヨブの死が語られる。いずれもラビ的説明であり、疫学的な記録ではない。

35a:9–10は特に慎重に読む。「相手にもばったのように見えたことを、どう知ったのか」という批判に対し、木に登った斥候が下の人々の声を聞いたという回答が続く。批判だけを切り出して結論としない。今回の一次本文では、木に登るのは斥候である。[研究文献との照合](constanza-cordoni-2025.md#checks)

35a:11–13は第九アブの記憶、石打ち、悪評を広めた者の死へ展開する。このWikiでは伝承の内容として記録し、現代の災害の原因を他者の罪へ帰す説明として適用しない。
