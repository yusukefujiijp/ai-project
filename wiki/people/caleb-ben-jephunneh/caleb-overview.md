<a id="name"></a>
## 2. 名前の意味をどこまで言えるか

古典的辞書BDBおよびStrongの項目は、כֶּלֶב（kelev／keleb、犬）との関連を扱う。Strongは同根の強さ・強制力との関連も可能性として挙げる。名前から犬の忠実さ、身分、氏族の由来まで一意に復元することはできない。古いトーテム説も確立した人物伝としては採用しない。[L1](sources.md#l1)

「全き心」という説明は、カレブの物語的な忠実さを表現するには適切でも、今回確認した辞書から確定できる語源ではない。כָּלֵבを単純に「全て＋心」に分解し、それを原義として示すことは避ける。**名前の由来と、本文がその人物をどう評価するかは別の問い**である。

<a id="genealogy"></a>
## 3. 家系は三つの層に分ける

**本文の配置。** 斥候はエフネの子と呼ばれる。一歴代誌4:15もエフネの子カレブと、その子イル、エラ、ナアムを記す。一方、一歴代誌2:18–20にはヘツロンの子カレブが登場し、アズバ、エフラテ、フル、ウリ、ベツァルエルへ続く。2章の人物と斥候を、説明なしに同一人物の家系図へ合成しない。

**ラビ的な統合。** Sotah 11b:23–24は、ヘツロンの子とエフネの子を結び、「エフネ」を斥候の助言から向きを変えた者という語釈で説明し、ケナズを継父とする。これは本文間の関係を解く伝承であり、出生記録を別途発見したことではない。[R4](sources.md#r4)

**現代研究の解釈。** D. G. Firth（2018）は、ヨシュア記14章のケナズ人という呼称を、外来のルーツを持ちながら忠実さを示す人物の文学的機能として読む。この見解は研究上の解釈として参照する。カレブ本人の民族的出自を独立資料で確証したものとは扱わない。[M2](sources.md#m2)

オトニエルとの関係には、ヘブライ語の「カレブの兄弟／親族」と「若い」の係り方、ケナズとの関係をどう読むかという問題がある。本文の呼称とSotahの異父兄弟説を分け、現代の家族関係用語で唯一の家系を確定しない。ヨシュ15:16–17で攻略対象はデビル／キルヤト・セフェルであり、ヘブロンと取り違えない。

## 4. 登場箇所への地図

次はマソラ本文の主要な明示箇所・氏族への言及をまとめた案内である。独立したすべての写本・翻訳の名称索引ではない。節番号は英語訳とヘブライ語本文で一部異なる。

| 箇所 | 内容・人物同定上の扱い |
|---|---|
| 民13:6,30 | ユダ族代表、民を静める発言 |
| 民14:6,24,30,38 | ヨシュアとの共同発言、別の霊、入地、生存 |
| 民26:65、32:12、34:19 | 世代交代の例外、ケナズ人、分配担当 |
| 申1:36 | 忠実さと本人・子孫への土地 |
| ヨシュ14:6–15 | 四十歳・四十五年・八十五歳、ヘブロン授与 |
| ヨシュ15:13–19、21:12 | アナク人、アクサ、オトニエル、畑と村 |
| 士1:12–15,20、3:9 | 相続・征服の再話、オトニエルとの関係 |
| 一サム25:3、30:14 | ナバルのカレブ人という呼称、カレブのネゲブ。本人の新しい出来事ではない |
| 一歴4:15、6:56（ヘブライ語番号6:41） | エフネの子の子孫、ヘブロン周辺の配分 |
| 一歴2:9,18–24,42–50 | ケルバイ／ヘツロンの子カレブ等の系譜群。斥候との同定を留保 |
