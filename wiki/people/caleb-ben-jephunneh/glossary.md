# 用語集

[入口](README.md) / [出典](sources.md) / [Graph](research-graph.md)

| 語 | このWikiでの意味と注意 |
|---|---|
| Torah | 狭義にはモーセ五書。ヨシュア記は五書に含めず、Tanakh内の関連本文として扱う |
| Tanakh | Torah・預言者・諸書からなるヘブライ聖書 |
| Pshat | 文脈・語法に即した基本的な読み。「現代歴史学が実証した史実」と同じではない |
| Derash / ミドラシュ | 語句・聖句間の関係を問う解釈。文学作品・文献群の名称にもなる |
| アガダー | 物語・倫理・神学などを含むラビ的議論。価値のない余談という意味ではない |
| ハラハー | 実践・規範を扱う議論。物語と完全に分離した世界ではない |
| Bavli | バビロニア・タルムード。引用箇所は巻・葉・面で示す |
| Sotah 34a / 34b | Sotahの第34葉の表側／裏側。章34という意味ではない |
| Tanhuma / Tanchuma | 同じ名称の異なる転写。複数の伝本・版を区別して参照する |
| Buber recension | S. Buberが刊行した系統の本文。通常版の同番号へ機械的に置換しない |
| Seder Eliyahu / Tanna DeBei Eliyahu | 文献名・伝統的呼称。Rabbah／Zutaと版の章番号を添える |
| ベイト・ミドラシュ | 学びと解釈の場。Seder Eliyahuのモーセの場面は再話上の設定 |
| לָשׁוֹן הָרָע / lashon ha-ra | 害を及ぼす悪い言葉・中傷。ここでは各伝承の用法を説明し、現代の法的判断は行わない |
| דִּבָּה / dibbah | 悪い評判・報告に関わる語。民13:32の語り手の評価に注意する |
| רוּחַ אַחֶרֶת / ruaḥ aḥeret | 「別の霊」（民14:24）。固定的な性格診断ではない |
| מִלֵּא אַחֲרֵי / milleʾ aḥarei | 従うことを全うする表現。「従い通す」「忠実である」等と訳す |
| אוּלַי / ʾulay | 「もしや／おそらく」等。ヨシュ14:12の留保を読む手掛かり |
| ネゲブ | 南方・南部の乾燥地域。本文ごとの地理的な使われ方を確認する |
| ヘブロン | חֶבְרוֹן / Ḥevron。祖先の墓、斥候、相続の物語が重なる場所 |
| キルヤト・アルバ | ヘブロンの旧名として示される呼称 |
| エシュコル | אֶשְׁכּוֹל / ʾEshkol、房。谷の名と、後代解釈で祖先の友の名が結ばれる |
| アナク人 | עֲנָקִים / ʿAnaqim。巨大さや恐怖の描写を、近代的な身体計測に置き換えない |
| ケナズ人 | הַקְּנִזִּי / ha-Qenizzi。ユダの代表という記述と併置される氏族的呼称 |
| 受容史 | ある本文・人物が後の文献でどう読まれ、描き直されたかを研究すること |
| 本Wikiの統合 | 出典を結んだAIの説明。各原典の語句・歴史的事実と区別する |

日本語の聖句説明は執筆AIによる要約を基本とする。現代英訳を長く転載せず、必要なヘブライ語の語句と節番号から原典へ戻れるようにする。神名は《創造主》などの表記を用いる。
