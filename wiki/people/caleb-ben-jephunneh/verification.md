## 4. 技術・公開の確認項目

対象は `yusukefujiijp/ai-project` の `main`。既存のRepository内Markdown方式に従う。ネイティブGitHub Wikiはmetadata上有効だが、公開 `/wiki` はRepository本体へ転送された。既存ページ一覧や設定画面は未確認であり、ネイティブWikiへは保存しない。

新設17ファイルと、人物索引への一行・版・更新日の追加を対象とする。既存人物本文を置換しない。公開前の原稿に対し、次の検証を実施した。

| 検証 | 結果 |
|---|---|
| Markdown | 新設16ページと人物索引の計17ファイルをパーサーで処理。19表と237リンクを認識 |
| 内部参照 | 相対パスとアンカーの欠落なし。新設ページに孤立なし。既存Wikiへの参照もRepositoryのtreeと照合 |
| 根拠台帳 | JSONL 28件を読込。ID重複なし。46件のclaims.refが実在する本文箇所へ接続 |
| Graph | 34ノードの一覧を確認。3図をMermaidパーサーで処理し、構文エラーなし |
| 表記 | metadata、改行、fenceを確認。神名表記の方針を検査 |
| 出典URL | 53個の固有URLへ通常のHTTP取得を試行。44個は200、8個は403、1個は503。API本文のエラーなし |

403はBrillのPDFとDOI、Mechon Mamre四章、大学書誌、BAS会員本文。503はFirth論文のDOI転送である。Brill本文とMechon Mamre、大学書誌は別途Web取得で読解し、FirthはSciELO公開本文を読解した。BAS会員本文は未読で、根拠に使用していない。HTTP制限・一時応答と、URLの消失や本文未読を混同しない。全外部URLの無制限な到達性を保証する結果ではない。

MarkdownとMermaidの構文確認は、GitHub上の画面を視認したこととは区別する。公開後の実画面確認の結果は会話内完了報告へ記す。

公開は最新mainを再確認し、競合を保持して一つのcommitにまとめる。参照先更新前に候補commitを読み戻し、更新には期待headを用いる。更新後は対象全ファイルを再取得して本文の一致を確認する。未実施の表示確認を検証済みとはしない。
