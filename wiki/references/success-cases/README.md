# Wiki Success Cases

Wikiで何が価値ある成果となり、どの条件と根拠があったかを、[success-cases.jsonl](success-cases.jsonl)へ残します。Humanの意味・評価とAIによる選定・解釈を区別し、原因の完全解明を保存の前提にしません。

初期収録は、ノイマン二経路の理解に関する一件です。ID `020e19b8-8ff5-463b-b903-aeda4298abc3` をファイル内検索してください。元の別読者報告は[Wiki Feedback](../feedback/README.md)が所有し、本事例は成功として取り上げる意味と成立条件を持ちます。同じ報告を独立した追加証拠として数えません。

形式・更新・保存後確認は[共有Success Casesの§6](../../../references/success-cases/README.md#6-共有caseの行形式と更新契約)を参照します。全Feedbackの成功事例化や固定件数を求めません。対象版の理解確認を、新しい人物や実利用・長期効果へ拡張しません。
