# Wiki Feedback

Wikiの制作・内容・読解・訂正・再利用への反応を、[feedback.jsonl](feedback.jsonl)へ対象・話者・文脈付きで残します。原文と編集要約、Humanの評価と別AIの報告を区別します。

初期収録の読む先は次のとおりです。IDはJSONL内で検索し、ID別アンカーを仮定しません。

| 問い | ID |
|---|---|
| なぜ制作経験を凝縮して残すのか | `6bcfedb6-f285-4883-a1dd-65d409bdebee` |
| ノイマン二経路について別読者は何を報告したか | `c47a4e18-4b0d-48d2-9e2b-46235c0fed06` |

速さ自体を求めず次回はAIへ委ねたいという先行Correctionは、[共有Feedback](../../../references/feedback/feedback.jsonl)のID `6640b806-e9fd-4f15-b20b-d385f22f25d6` が所有します。

行形式・読取・更新・保存後確認は[共有Feedback契約](../../../references/feedback/README.md)を参照します。Wiki固有の対象は本書に残し、形式を重複定義しません。反応を残すことは、新しいTask・実行承認・効果実証を意味しません。
