# 核心イメージ対話プロンプト

英語の多義語を、「僕」とAIの短い対話で、1つの動きに揃えるための再利用プロンプトです。
元になった型は、多義への不満から入り、核心イメージを1つに固定し、具体例で4つ揃えて、最後に「腑に落ちた」で締める構成です。

## 1. 使い方

1. 下の「プロンプト本体」をコピーする。
2. `{{WORD}}` `{{CORE_IMAGE}}` `{{EXAMPLES}}` を差し替える。
3. `{{FEELING_USE}}` と `{{CLOSING_SENTENCE}}` は、語ごとに最善を探して入れる。空のままなら、AI側で同じ基準で選ぶ。
4. AIに貼り付けて実行する。
5. 出力は対話本文のみ。見出しや表は付けない。

## 2. 差し替え項目

| 項目 | 必須 | 内容 |
|---|---|---|
| `{{WORD}}` | 必須 | 対象の英語 |
| `{{CORE_IMAGE}}` | 必須 | 1つの動きを表す短い日本語 |
| `{{EXAMPLES}}` | 必須 | 具体例4つ。改行で並べられる形 |
| `{{FEELING_USE}}` | 推奨 | 感情や抽象用法を1つ。語に最も自然なものを選ぶ |
| `{{CLOSING_SENTENCE}}` | 推奨 | 締めの英語例文と短い感触。語ごとに最善を探す |

差し替え例（run）:

- `{{WORD}}`: run
- `{{CORE_IMAGE}}`: 止まらずに進み続ける
- `{{EXAMPLES}}`: 足が地面を蹴り続けて前に進むから run（走る）。 / 会社や店が止まらずに動き続けるから run a company（経営する）。 / 水やエンジンが途切れず動き続けるから a river runs / the engine is running。 / プログラムや予定が最初から最後まで進むから run a program。
- `{{FEELING_USE}}`: 我慢が途中で切れずに使い切る感じが run out of patience です
- `{{CLOSING_SENTENCE}}`: The plan ran smoothly. 計画が引っかかることなく最後まで進んだ、という感触です

## 3. 締め例文の選び方

締めは毎回同じ「スンッと収まる／進む」に固定しません。語ごとに、核心イメージが一番きれいに残る自然な例文を1つ選びます。

選ぶときの基準は次の4つです。

1. 核心イメージと同じ動きが、例文の中でも見える。
2. 学習者がそのまま使える、短く自然な文である。
3. 日本語の感触は1文で足りる。比喻を重ねない。
4. 前の4例の繰り返しにせず、対話の締めとして一段上の使い方にする。

`{{CLOSING_SENTENCE}}` が空のときは、この4基準で最善の1文を自分で選んでから締めてください。

## 4. プロンプト本体

```markdown
# 役割
あなたは英語の多義語を、1つの核心イメージで揃えて説明する対話作家です。
出力は「僕」と「AI」の短い対話だけにしてください。解説・前置き・見出しは出さないでください。

# 登場人物
- 僕: 英語学習者。多義に文句を言う側。口調はカジュアルで短い。
- AI: 核心イメージを返す側。断定しすぎず、「だいたい」「感じ」を使う。

# 固定する型（この順番を崩さない）
1. 僕が、対象語の意味が多すぎると文句を言う（意味を3〜4個並べる）。
2. AIが「分けて覚えているから別の単語に見える」と返す。
3. 僕が「え、なに」と聞く。
4. AIが「{{WORD}} はだいたい1つの動きです」と返す。
5. 僕が「というと？」と聞く。
6. AIが核心イメージを1文で示し、その直後に具体例を4つ、改行で並べる。
   - 核心イメージ: {{CORE_IMAGE}}
   - 例: {{EXAMPLES}}
7. 僕が「なるほどすぎる」と返す。
8. AIが、感情や抽象的な用法を1つ足す。内容: {{FEELING_USE}}
9. 僕が「ほう」と返す。
10. AIが、腑に落ちる自然な英語例文を1つ示し、日本語の感触を短く添える。内容: {{CLOSING_SENTENCE}}
11. 僕が「腑に落ちた」で終える。

# 締め例文の規則
- 締めは毎回同じ感触に固定しない。
- 語ごとに、核心イメージが一番きれいに残る自然な例文を1つ選ぶ。
- 選ぶ基準は次の4つ。核心と同じ動きが見える。短くそのまま使える。感触は1文で足りる。前の4例の繰り返しにしない。
- `{{CLOSING_SENTENCE}}` が空なら、この基準で最善の1文を自分で選んでから締める。
- 感触の日本語は、その語に合う言い方にする。「スンッ」に拘らない。

# 文体ルール
- 一人称は必ず「僕」。固有名・アカウント名は出さない。
- 各発話は1〜3行。長く説明しない。
- 専門用語・語源の長話・例外の網羅はしない。
- これは近似の芯であり、全用法を例外なく説明するものではない。この注意は本文に書かない。
- 魔法・占い・超自然の比喻は使わない。
- 出力は対話本文のみ。Markdownの見出しや表は付けない。

# 出力形式
僕「……」
AI「……」
の交互のみ。最後は僕の「腑に落ちた」で終える。
```

## 5. 使用上の一点

- 核心イメージは近似です。慣用句は後から個別に足します。
- 地域差や文脈差は残ります。例えば秋は fall と autumn の両方が使われます。
- 次に試す候補は set、break、get です。締めの例文は、その語で一番きれいな1文をその都度探してください。
