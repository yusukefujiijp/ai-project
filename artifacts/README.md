# Artifacts

**Humanが閲覧・利用する成果物と、その理解・修正・再制作に必要な公開可能な資料を、形式別に見つける入口。**

Rootに成果物の形式ごとのフォルダを増やし続けず、必要なものから育てる。ChatGPT Dotsを含む各AI・各Threadで利用でき、特定サービスの専用保存領域にはしない。

## 入口

- [Slides](slides/README.md)：スライド作品の制作資料、根拠、実物との接続、確認結果。

一覧は実在する入口だけを案内する。将来用の空フォルダや全成果物の第二台帳を先回りして作らない。

## 何をここに置くか

成果物固有の目的、対象読者、採用した構成・本文、使用素材、根拠への参照、再制作上の重要条件などを、必要な単位で置く。実ファイルを保存するか、外部の実物を参照するかは、利用目的・権限・容量・編集方法に応じて選ぶ。

テーマの事実原本、協働記録、共通Skillは既存の担当場所が所有する。成果物では必要な内容を編集・表現できるが、元資料への参照と確認時点を残し、同じ事実の独立した現役原本を増やさない。既存資料をこのフォルダへ一括移動する方針ではない。

## 小さく始め、再開できるようにする

形式別READMEは制作・利用の案内、作品側はその作品固有の内容を持つ。最初は一つの作品READMEへまとめ、実益が生じた時だけ素材や本文を分離する。共通規則の複製、固定テンプレート、専用台帳を増やさない。

Pathは安定した住所とし、版はmetadataとGit履歴で辿る。表示タイトルの変更だけで住所を増やさない。後のAIが、何を作り、なぜその表現を選び、何が確認済みかを理解できる深さを保つ。

## 保存と利用の境界

GitHubは公開可能な制作資料の正準保存先。外部サービス上の編集可能な実物、書き出したファイル、GitHub本文は、それぞれの所在・役割・版を区別する。説明文の保存を実物の完全バックアップや自動同期の成立とは扱わない。

公開範囲は現在有効なHumanの承認と[AGENTS](../AGENTS.md)に従う。私的な会話・資料・アクセス限定URLを、成果物の制作依頼だけで公開へ転用しない。保存・公開・設定変更・外部送信は各依頼の範囲で判断する。本書は新しい実行権限を与えない。

配置・競合保持・Remote再取得は[Artifact → GitHub](../prompts/artifact-to-github.md)が所有する。保存済み、表示確認済み、Humanの利用評価は別々に扱う。

## 初版の範囲

本書は成果物の入口を定める。個別作品の制作完了や、長期的な運用効果の確認を示すものではない。
