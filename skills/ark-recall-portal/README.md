# Recall Hubへの移動案内

既存ark-recall-portalの利用名は **Recall Hub / recall-hub** へ継続改名しました。

用途・標準Query・形成と確認範囲は [Recall Hub README](../recall-hub/README.md)、現在の判断方法は [SKILL.md](../recall-hub/SKILL.md) が所有します。利用する際は現行SKILL.mdを全文読み、必要なSourceへ進んでください。ここへ可変本文を二重保存せず、別の旧Skillとして導入しません。

経験データの[入口](../../ark-recall-portal/README.md)・[items](../../ark-recall-portal/items.json)は元の住所を保持します。過去の名称・Identity・固定Bindingは、その資料が指定する版から確認してください。[改名前のREADME](https://github.com/yusukefujiijp/ai-project/blob/5746930c9f9358aec589967cd2354a5b0a368440/skills/ark-recall-portal/README.md)も履歴として復元できます。

旧URLからの読取経路は、製品での旧コマンド別名対応や固定Binding移行の証明ではありません。取得不能・表示切れは現行原本の未読範囲と影響を示し、未読を適用済みとしません。
