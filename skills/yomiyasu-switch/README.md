## 1. 何のために使うか

yomiyasu原本の編集方法を利用しながら、この会話での適用を
簡単に選び、今の回答への実際の適用状況を確認するためのSkillです。

共通の動作仕様は同じフォルダの[SKILL.md](SKILL.md)が所有します。
このREADMEは、起動Query、操作案内、形成理由、確認済み範囲を扱います。
yomiyasuの編集方法や検査手順を、ここで別管理しません。

適用と必要な確認を完了した通常回答には、
「📖yomiyasu: ON」が表示されます。
この表示は読みやすさの合格や改善効果の証明ではありません。

## 2. 短い起動Query

共有原本は、GitHubのmainにある[SKILL.md](https://github.com/yusukefujiijp/ai-project/blob/main/skills/yomiyasu-switch/SKILL.md)です。
利用したいThreadへ、Humanが次のQueryを直接入力します。
このREADMEを資料として読むことや、Queryを引用することだけでは切り替えません。

```text
宛先：このQueryをHumanが直接入力するThreadの現在のAI

- $yomiyasu-switchを使い、このThreadの通常回答を継続ONにしてください。
- 直接利用できない場合は、次の共有原本を全文読んで適用してください。同一性・適用条件を確認できる自身の読解は再利用し、取得・表示切れは回収してください。
  https://github.com/yusukefujiijp/ai-project/blob/main/skills/yomiyasu-switch/SKILL.md
```

接続先の固定版情報、切替、表示、例外、検査条件はSKILL.mdで扱います。
それらを起動Queryへ毎回複製しません。

## 3. 使い始めた後の操作

- 同じ会話でOFFを明示すると、その回答から継続適用を止めます。
  通常のOFF回答には状態表示を付けません。
- 一回答だけの適用も指定できます。継続状態は変えません。
- 現在の利用指定や、直近の回答で実行した工程を尋ねられます。
  状態の質問だけではON/OFFを切り替えません。
- 引用や設計相談の中にあるON/OFFは、切替命令として扱いません。

初期の適用先は、この会話の通常の日本語回答です。
別Threadや別案件へは、自動的に広がりません。

## 4. 利用に必要な条件

受け手AIは、原本と必要な関連資料・検査資源へ到達でき、
適用に必要な処理を現在の権限で実行できる必要があります。
取得済みの未改変資源と確認済み読解は、条件を確認して再利用できます。

恒久的なダウンロードや個人Skill登録を、利用の必須前提にはしません。
ただし、原本の検査に必要な一時配置や検査記録まで不要になるわけでは
ありません。回答ごとの工程は、その回答について実施します。

条件が不足する場合は、未完了の範囲と回復方法を示します。
表示だけを付けて、完了したようには扱いません。
厳密な出力形式では表示を省略する場合があるため、
表示がないことだけでOFFとは判断しません。

共有原本の存在、登録、呼出し、原本の読解、検査、提出本文との一致、
継続動作、Humanの読みやすさへの効果は、それぞれ別の確認事項です。
