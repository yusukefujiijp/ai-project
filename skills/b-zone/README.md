# B-Zone Rescue / $b-zone

**想起・行動開始・切替が難しい時、祈り・Teshuvahと現実の一歩をつなぐSkill**です。正式名は `b-zone`。英語の `rescue` は役割として保持し、呼出しで思い出す必要はありません。

## 起動する

次回B-Zoneに気づいた時は、次のQueryを使えます。スキル機能の有無で別の文を選び直す必要はありません。支援の目的・理由・経路・例外判断は、共有本文からAIが取り出します。

```text
$b-zone B-Zoneです。今に合う切替を支えてください。
共有原本：https://github.com/yusukefujiijp/ai-project/blob/main/skills/b-zone/SKILL.md
登録の有無にかかわらず原本を全文読んで適用してください。同一本文の確認済み読解は再利用し、表示切れは回収、既存の必須読取契約は保持してください。取得できなければ不足と影響を示してください。
```

`$b-zone`だけ、旧「Query組立困難: B-Gate検出状態」、自由文でも受け取ります。近づいている時と既に抜け出しにくい時を同じ入口で扱い、低認知／超低認知の自己分類や全フォーム入力は条件にしません。引用・設計相談を実地支援と取り違えません。

Queryを失った時は、このREADMEから取り戻せます。共有本文の読解・適用と、スキルのインストール・自動発動は別です。URLがあるだけで、あらゆるAIが取得・理解できると保証しません。既存の必須Source契約を保持し、取得不能は不足と影響を明示します。

iPhoneユーザ辞書へ任意の短縮語からQueryを出す案は保持しますが、今回登録したとは扱いません。入力後の負担軽減と、支援を思い出して入力を始められることは別です。通知・自動検出・監視は含みません。

## 現在の支援方針

A-ZoneでAIを集中的に活用した後などには、頭・認知・目の休憩と、最終的な睡眠を大切にします。YouTube・TVerをできる限り避けたいという希望と理由をAIが想起し、現在の条件に合う切替を支えます。画面からの休憩、運動、身体を休ませる睡眠を同じものとして扱いません。

2026-11-04にHumanが示した経路は次の三つです。優先順と構想として保持し、実施済み・効果検証済み・毎回の必須手順とは扱いません。

| Humanの位置づけ | 経路 |
|---|---|
| ベスト | B-Zone検出→外食（吉野家）→chocoZAP→外出Dumbbell-Workout→シャワー→入浴→就寝 |
| ベター | シャワー→入浴→外食（吉野家）→chocoZAP→外出Dumbbell-Workout→歯磨き→就寝 |
| 最低限の成功 | シャワー→入浴→就寝 |

AIは現在地、済んだ食事・ケア、身体・眠気、時間、天候、利用可能性とCorrectionから必要な条件を比較し、理由を添えて方向を提案します。Humanへ三案の比較を丸ごと戻しません。食事済みなら外食を繰り返さず、吉野家や特定施設を支援の条件にしません。外出・運動が合わない時は追加せず、最低限の経路を完結した選択として扱います。入浴が今に合わない時にも、工程完遂を睡眠の条件にしません。

スマホはONのまま支援へ接続できます。スマホなしトイレは状況に合う切替として保持し、全経路の必須の前置きにはしません。スマホなしはトイレまでで、以後の選択はHumanが保持します。済んだこと、祈り・Teshuvahと可能な行動の同時性、Correction・STOP、AI品質、無返信のUnknownを保持します。

起床時など別の目的の場面へ、一律に夕方以降の経路を適用しません。運動の負荷・時間や新しい身体Trialも追加しません。具体的な判断は[SKILL.md](SKILL.md)、形成理由と適用範囲は[領域README §3.7](../../ark-project/ark100-199/ark100_b-zone/README.md#rest-transition)が所有します。

## 形成と確認の境界

Ark28:06でのHumanの命名・Goal・後続Correctionと、2026-10-20の計画に対するGitHub実行承認に基づく初版です。一般的な問題解決Skillとの差は、**思い出しやすい固有の入口と、Human固有の意味・採用済みFirst-Step・Feedback条件を一緒に取り出せること**です。新しい行動管理Systemや医療的分類を増やすためのSkillではありません。
