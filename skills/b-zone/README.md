# B-Zone Rescue / $b-zone

**想起・行動開始・切替が難しい時、祈り・Teshuvahと現実の一歩をつなぐSkill**です。正式名は `b-zone`。英語の `rescue` は役割として保持し、呼出しで思い出す必要はありません。

## 起動する

一語だけでも支援を求められます。

```text
$b-zone
```

まだ近づいていると気付けた時には、例えば次を使えます。

```text
$b-zone もうすぐB-Zoneです。どうすればよいか分かりません。今の状況から、祈り・Teshuvahと可能な行動へつながる一歩を支えてください。
```

既にハマって抜け出せない時には、例えば次を使えます。

```text
$b-zone 今B-Zoneにハマっていて、どうすればよいか思い出せません。祈り・Teshuvahと可能な行動へつながる一歩を支えてください。
```

二つは別Skillでも別Thread種別でもありません。低認知・超低認知を自分で判定できなくても、長いQueryを打てなくても使える設計です。引用やSkill設計の相談を、その場のRescue発動とは扱いません。

iPhoneユーザ辞書へ、例えば `bzz` から上のQueryを出す準備はHumanの採用案です。ここで辞書登録を完了したという意味ではありません。辞書は入力を始めた後の負担を減らせますが、**支援へ来ることの想起まで保証しません**。

## 現在の支援方針

現在の第一歩は、状況に合えば **スマホなしでトイレへ向かう**。スマホなしはトイレの行動が済むまでで、**その後は自由**です。支援へ到達する前の電源OFF、トイレ後も続く一律のスマホ禁止、返信・完了報告は前提にしません。

祈り・Teshuvahは行動と同時に続けられます。Workout・chocoZAPは重要な接続です。シャワー・入浴の毎回実施や全工程の完遂は固定せず、現在の場所・意向・天気・時間・身体条件と、既に済んだ仕事から選びます。眠れる時は眠る方向も扱います。

「無理」「違う」「もう済んだ」「STOP」を、それぞれの意味で受け取り直します。詳しい自己説明を支援の利用条件にせず、返答がない場合の結果はUnknownのまま保持します。AIの検討品質や必要な説明を下げる指示ではありません。

## 形成と確認の境界

Ark28:06でのHumanの命名・Goal・後続Correctionと、2026-10-20の計画に対するGitHub実行承認に基づく初版です。一般的な問題解決Skillとの差は、**思い出しやすい固有の入口と、Human固有の意味・採用済みFirst-Step・Feedback条件を一緒に取り出せること**です。新しい行動管理Systemや医療的分類を増やすためのSkillではありません。

初版では、短い呼出し、近づいている場面、既にハマった場面、済んだ行動・天候・体調への対応、眠れる時、Correction・STOP、設計相談との区別を限定確認します。検証で作った相談はHumanの実経験ではありません。実際の保存・登録・再取得結果は上記Hubの記録へ戻ります。

朝の「スマホなしトイレから生活行動へ進めた」という本人報告はArk100原本に保持しています。これは本Skillの利用成功や超低認知状態での効果の実証ではありません。試行の結果やCorrectionが届いたら、詰まった接続を改善します。会話中の支援修正と、Skill原本の永続改訂の権限は別です。

Ark100:00、独立した各ケースThread、使用中とは別の未使用・準備済みThreadは、Humanが採用した次の運用準備です。本Skillの作成によって、実際のProject・Thread起動、ユーザ辞書登録、身体Trialまで完了したとは扱いません。
