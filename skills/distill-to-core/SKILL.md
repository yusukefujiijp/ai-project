# 一言言語化

対象ごとに、現在の問いと文脈を最もよく捉える核を選び、短語の対応表で返す。必要な検討を十分に行い、短さは指定された出力部分に適用する。語の選択方法や検討候補数は固定しない。

## 文脈に合う核を選ぶ

- 「本質」を、この文脈で対象を捉える中心語として扱う。普遍的な唯一の定義や、対象の全情報の代替としない。
- 観点は、Humanの明示、会話から明らかな目的、対象群から自然に読める着眼点の順に解決する。十分明らかなら確認を挟まない。
- 比較する表では、中心的な働き、成果の質、取り組む姿勢など、今回答える関係と粒度をできるだけ揃える。異なる観点が明示されている場合は、その違いを保持する。
- 対象の意味と指定順を保持する。広い対象を黙って狭い活動へ置き換えない。語の正確さが観点によって大きく変わり、文脈でも解決できない場合だけ、必要な点を短く確認する。
- 一つの核を表す自然な一語、またはごく短い複合語を優先する。重要な限定や自然さを保つために必要な場合だけ、ごく短い名詞句を使う。対象から既に分かる修飾語を繰り返さず、短い説明句になったら中心語へ絞る。所属カテゴリだけを答えず、列挙で複数の核を詰め込まない。短さのために不自然な造語を作らない。
- 根拠のない原因・人格・信仰状態を言い切らない。活動と核語の対応を、能力向上の実証や因果の証明へ変換しない。重要な不確実性を短語で隠してしまう場合は、必要最小限の確認・限定を優先する。

## 対応表を返す

通常は次の二列だけのMarkdown表を、前置きなしで最初に返す。対象が一件でも一行の表でよい。

| 対象 | 本質 |
|---|---|
| 対象名 | 核を表す短語 |

- 本質のセルには、括弧、補足説明、理由、評価、複数候補の併記を入れない。語を引用符で囲む必要もない。
- 説明が求められていなければ、表だけで完了する。締めの解説、自己採点、次の提案を加えない。
- 同じ依頼で理由も求められていれば、表の後で説明する。後続の解説・訂正依頼には、その依頼に必要な密度で応じる。
- 現在の明示形式と上位契約を優先する。二列表が求められている場面では、通常のGraph表を満たすための列や別表を追加しない。
- この出力規則を、他の議題や通常の深い対話へ常時適用しない。スキルの引用・設計相談を、そのまま表出力の実行指示にしない。

## Few-Shotから粒度を掴む

次は、活動に関わる中心的な認知の働きを拾う例として読む。固定辞書や唯一の正解にせず、現在の観点に応じて選び直す。

| 対象 | 本質 |
|---|---|
| 哲学を読む | 推論 |
| 数学 | 抽象化 |
| 討論 | 論証 |
| 写真 | 観察 |
| リサーチ | 吟味 |
| ジャーナリング | 自己観察 |

境界例も語の選択に使う。

- 写真を被写体への注意から捉えるなら「観察」、画面の組み立てからなら「構図」、出来事を残す役割からなら「記録」を候補にできる。
- 「チェス → ゲーム」は所属分類に留まる。今回求められた核を選ぶ。
- 「音楽 → 記憶と協調」は二つの核を含む。観点から一つを選べるか判断し、説明なしに「音楽」を「合奏」へ狭めない。
- 「情報の吟味 → 吟味」は文脈次第で意味を保てる。「自己観察 → 観察」は自己へ向く意味を失い、「抽象化 → 抽象」は働きの意味を変える。削除後の意味で判断する。

## 送信前に意味を確かめる

同じ観点・釣り合う粒度で並ぶか、一つの核として言い切れているか、対象に忠実か、意味を失わず削れる語が残っていないかを確認する。文字数の均等化や、行ごとの語の重複回避を目的にしない。同じ核語でも対象同士の同一性や共通因果は断定しない。

Humanの訂正があれば、対象・観点・核語のどこが変わったかを読み、必要な範囲を選び直す。一言を深い説明へ戻る入口として使い、元の文脈を再取得できない場合は推測で復元しない。
