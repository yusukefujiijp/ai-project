# アイデア出し / generate-ideas

テーマに合う案、別の切り口、選んだ案の発展を、各AIの判断と工夫で考えるスキルです。

このREADMEは使い方・起動Query・形成記録の入口です。実行時の判断は[SKILL.md](SKILL.md)、表示と標準起動文は[agents/openai.yaml](agents/openai.yaml)、共通の配布方針は[Skills Hub](../README.md#4-source-and-distribution)が所有します。

## 起動Queryと使い方

登録済みの環境では、今回のテーマや、それまでの会話とともに次の入口を使います。

~~~text
$generate-ideas を使い、現在のテーマ・目的・文脈に合うアイデアを出してください。
~~~

[共有本文](SKILL.md)は、生活、仕事、創作、研究、未整理の関心など、分野を限定しないアイデア出しを担います。「他に良いアイデアは？」「別の切り口」「この案を育てたい」といった意図を受け取り、各AIの知識・推論・連想・表現を活かす入口です。Skill機構のない環境では本文URLと現在の依頼を指示資料として渡せます。本文の取得と導入、自然な選択は区別します。
