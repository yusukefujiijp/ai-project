# write-textへの互換案内

現行の用途・標準Query・形成記録は[Text WriterのREADME](../write-text/README.md)、実行時の方法は[共有SKILL.md](../write-text/SKILL.md)にあります。Skillを直接利用できない場合は、そのSKILL.mdを全文読んで適用してください。

同じ既存登録物を継続し、この旧フォルダを第二の現行Skillとして配布・導入しません。旧共有URLからの到達と旧名での自動呼出しは別です。既存QueryのURLはこの案内から現行原本へ進めますが、旧名の自動別名対応は保証しません。

当時の説明・Query・確認結果は[改名前の固定版README](https://github.com/yusukefujiijp/ai-project/blob/47d0d3ce2550de8f3e0f401b5af82af3b3a5f4f1/skills/write-ark-markdown/README.md)で確認できます。形成記録は現行READMEにも保持しています。固定Bindingで旧本文を指定されている場合は対象契約の固定版に従い、この改名で移行済みとは扱いません。
