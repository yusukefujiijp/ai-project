# Token Burning Mode / トークン消費モード

指定されたAI利用枠を、承認済みの価値ある仕事へ集中的に配分し、成果品質とHumanの権限を保持しながら、利用可能な時間内に残量を限りなくゼロへ近づけるSkillです。

Reset券の期限から逆算する場合と、今ある利用枠を集中的に成果へ変えたい場合の両方を扱います。Resetは、対象と条件が別途委任されている場合に接続します。

共有本文は、後からHumanが目的・判断・権限・停止理由を点検できる日本語で保持します。名称や必要な機械用識別子は英語を使えます。

## 使う場面

- 承認済みの仕事へ利用枠を集中配分し、残量を限りなくゼロへ近づけたい。
- Reset券の期限より前に、成果へ変換する十分な時間を確保したい。
- 終盤の作業粒度や並行数を調整し、成果の区切りと回復へつなぎたい。

配分先は、Humanの指定を保ち、現在のGoalに結び付く承認済みの有効な残作業を優先します。AIが進められる部分とHumanの判断に依存する部分を切り分け、委任内の作業・検証・通常修正を進め、必要に応じてHumanの判断と後続AIの再開に使える準備へつなぎます。結果やCorrectionに応じて、この切り分けを更新します。

「期限の約1時間前にResetする」という条件がある場合、消費開始はそのさらに前へ置きます。必要時間は仕事と環境から判断し、固定の一時間・数時間・残量%を万能値にしません。

残量確認、券の付与・手動使用の報告、名称の相談だけを、消費実行の依頼にはしません。
