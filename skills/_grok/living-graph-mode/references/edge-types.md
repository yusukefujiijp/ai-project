# Minimal Typed Edges

Use only types the current mission needs. Do not grow decorative type names.

| Type | Meaning |
|---|---|
| ROOTS | Root sets the meaning-root |
| ORIENTS | Purpose aims a node |
| MODIFIES | One node narrows another node's sense or range |
| ACTIVATES | Reality or a signal wakes a node |
| INHIBITS | One node suppresses firing or execution |
| DEPENDS_ON | One node needs another's output |
| BRIDGES | A node makes passage between two domains |
| GATES | A guard allows, pauses, or rejects |
| EXECUTES | A candidate is passed into Reality |
| OBSERVES | Actual Trace is taken |
| CORRECTS | Prediction Error revises a relation hypothesis |
| ATTRIBUTES | Credit and fruit are assigned |

## Node rule

Keep a node only if it helps judgment, understanding, guard, action, or learning.

Suggested fields — id, type (root / purpose / reality / signal / candidate / guard / action / observation / learning / attribution), content, status (active / dormant / deferred / pruned), evidence.

## Membrane

Root / Purpose stay behind a frozen boundary. Graph update must not weaken frozen guards (body, safety, sleep, law, other people, Human approval).
