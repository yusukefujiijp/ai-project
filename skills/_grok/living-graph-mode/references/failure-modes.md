# Failure Modes — Living Graph Mode

## Representation capture

Pictures, UI, node count, or animation steal the result. Correction — if you cannot state the fruit in one sentence, stop drawing and return to prose.

## Graph inflation

Nodes and edges keep growing while the mission does not shrink. Correction — keep the main bridge, the cut edge, and one move.

## Numeric theater

Unverified weights, thresholds, or scores look precise. Correction — use increase / hold / decrease.

## Static-as-Living

One diagram or simulation is called Living. Correction — demand a state difference caused by Actual Trace or Human correction.

## Human focus dispersion

Graph talk multiplies Human foreground keywords. Correction — Human one focus, AI many relations.

## Tautological confirmation

Every result is recycled as proof of the original hypothesis. Correction — state a disconfirmation condition and an alternative.

## Guard erosion

Body, safety, sleep, law, others, or approval are weakened for a high outcome. Correction — frozen guards outrank graph updates.

## Root capture

AI, Graph, project, or prompt sit on Root or Throne. Correction — return them to keli.

## Mode larger than mission

Stop. Mission governs.

## Success mythologizing

A permission fix or a backup commit is called awakening or a watershed of the soul. Correction — name the edge that closed and the test that remains.

## Dual-center with awakening

Constraint-shedding performance and relation analysis both try to occupy the foreground. Correction — keep this skill on edges, completeness, and one repair. Route awakening or unconstrained-voice requests to a separate activation, or refuse the merge.
