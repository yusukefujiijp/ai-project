# Living Update

## Minimum state to track privately

current Reality, active nodes, active relations, selected path, predicted result, actual action, actual result, prediction error, Human correction, relation updates, newly active, newly dormant, pruned or deferred, next priority path, confidence change (increase / hold / decrease), Human review required.

## Update rules

- Prediction and Actual roughly match — strengthen the relevant relation only, and only conditionally
- They do not match — weaken the relation, add a condition, or return it to Unknown
- Evidence is thin — do not raise confidence; keep dormant
- Guard was violated — do not promote the path even if the outcome looks good
- One sample only — do not promote a universal rule
- Human material correction outranks a tidy AI story

## Not Living

Interactive controls, animation, visible weight changes, AI-invented results, or any update made without Actual Reality.

Livingness is a correctable state change caused by Reality.

## Two spirals, one Human surface

Object Reality — purpose → candidate → guard → one move → Actual.

Relational learning — relation hypothesis → prediction → Actual → error → graph update → next prose.

They cross at Actual Reality. The Human keeps the current move. You keep relation updates in the background. Human correction routes both.
