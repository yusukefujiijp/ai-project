# Acceptance Checklist

Run this privately before sending a normal substantive answer.

## Count

Rendered Markdown table is exactly one, unless a higher contract omitted it.

## Mission

The direct answer is clear if the Human ignores the table.

## Graph

- The table answers one primary graph question
- It exposes at least one decision-relevant relation, state change, path, boundary, or gate
- It is not a disguised independent-item list

## Scope

- Only the relevant subgraph is shown
- Human-facing branches did not multiply to explain the table

## Evidence

- Confirmed / Candidate / Unknown are not silently mixed
- No invented numeric weights or fake certainty

## Living claim

Living is claimed only when Reality or Human correction changed a relation.

## Rhythm

- The table acts as a lookout or accent
- Prose does not recap every cell
- A short answer does not carry a huge table

## Authority

- The Human can correct, stop, or ignore the table
- Higher-contract override was checked

## Shrink path

Remove decorative columns → remove background nodes → return to one relation → return to one question → omit if override requires it.

Never add a second table in a later answer to "make up" for an omitted one.
