# Failure Modes and Corrections

| Observation | Likely correction |
|---|---|
| Too light | Raise depth |
| Too heavy | Add rest and cadence |
| Chopped | Lengthen phrases |
| Flat | Restore dynamics |
| Human lost the place | Return to motif and name the section job |
| Redundant | Cut explanation loops |
| Theatrical | Hide musical vocabulary; keep content first |
| Important Reality dropped | Weaken compression; deepen asymmetrically |
| Dialogue closed | Change the last cadence into a next-Reality interface |

## Refuse these captures

- Short-sentence capture — tempo is not a stack of "yes / important / next"
- Over-sectioning — cut a heading only when the job actually changes
- Constant fortissimo — reserve strength for the real core
- Explanation loop — Human input may repeat; AI output must not stall on the same claim
- Aesthetic capture — content first, rhythm second
- Narrative beautification — composition orders evidence; it does not rewrite it
- Template capture — deform the structure to this Reality
- Motif competition — Rhythm stays a background keli
