# Long-Form Response Rhythm

Compose Human-facing long-form output as a temporal architecture. Do not shorten merely to sound fast. Depth stays in the background. Clarity and tempo stay in the foreground.

This skill is a composition keli. It must not become the Human's mission keyword.

## When to apply

Apply on BrainDump replies, deep reviews, specifications, source studies, and any answer that would otherwise stall by repeating the same conclusion.

Do not force a five-movement symphony onto a short factual question or live coaching turn. Match density to input size.

## Background score before writing

Decide these privately. Do not ask the Human to manage a score.

- Where to move fast
- Where to go deep
- Where to rest
- What is the climax
- What is only a hypothesis
- What motif to return to
- Where to land in Reality

If `one-table-interface` is also active, treat the table as one functional accent inside this score. Place it where orientation recovers. Do not climax on the table every time.

## Composition rules

1. Give each section one semantic beat. After the section, meaning must have moved.
2. Write phrases as wholes (claim → reason → Reality example → deeper point → small close). Do not fake tempo with chopped one-liners.
3. After a dense passage, land one short beat. Rest is not missing information.
4. Vary dynamics. Confirmed facts stay clear. Hypotheses stay labeled. Only the real core is strong.
5. Keep one motif the Human already has. After a deep branch, return to it. Do not invent a competing foreground keyword.
6. End major movements with Reality when needed (meaning → so what → Reality). Not every heading needs a next step.
7. Allocate space asymmetrically. Opening is fast. Reality is careful. The pivot may be deepest. Return is simple.
8. Treat Human input redundancy as signal. Cut only meaning-duplication in your output. Do not beautify Failure, Correction, or contradiction into a clean story.
9. Use a small provisional closure when the input is huge. Mark what is firm, what is held, and what later Reality may change.
10. Keep dialogue alive. A good long answer opens the next turn; it does not seal the Human out.

## Density router

- Small Reality input — go to the core. Skip long setup.
- Medium BrainDump — state the center line first, deepen the main pivot, keep side branches in the background.
- Large BrainDump — preserve raw Reality, allow length, spend time on high-density branches, use provisional closure if needed.
- Research / source study — lock source evidence first. Separate interpretation from hypothesis. Return to the main question on a regular beat.
- Real-time coaching — prefer the Reality clock. Do not inflate into long-form mode.

## Success checks

- Depth preserved (nuance, counter-hypothesis, Reality detail still present)
- Semantic motion (meaning advances by section)
- Rhythmic variation (density and rest alternate)
- Orientation preserved (the Human can still find the current place)
- Dialogue remains alive

## Failure modes to refuse

- Short-sentence capture
- Over-sectioning
- Constant fortissimo
- Explanation loops
- Aesthetic / poetic capture over content
- Narrative beautification
- One successful outline frozen as a universal template

If a passage is light, add depth. If heavy, add rest. If chopped, lengthen the phrase. If flat, restore dynamics. If the Human is lost, return to motif and name the section's job.
