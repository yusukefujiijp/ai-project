# 暮らしの工夫・共同設計 / co-design-everyday-solutions

身近な物・空間・手順を、本人の目的と制約に合う具体案へ組み立てるスキルです。DIY・料理・収納などの実用上の工夫を扱い、単なる事実確認やTask一覧の管理とは区別します。

## 起動Query

今回の対象や場面とともに使います。次は現行UIの標準起動文です。

```text
$co-design-everyday-solutions を使い、今ある物や生活の条件から、使いやすい工夫や選択肢を一緒に考えてください。
```

## 使い方と担当原本

今ある物、使う場面、困っていることを、分かる範囲で伝えられます。完成した解決案や定型フォームは必要ありません。準備から片付けまでの負担と成立条件を見て比較し、提案・本人の評価・現物の結果を区別します。
