# Plan Mode / plan-mode

現在の依頼と未整理の意図を十分に調査・言語化・比較し、Humanが判断できる計画を提示して止めるスキルです。短い入口からも必要な検討を担い、変更しないという境界を保ちます。

## 起動Queryと使い方

登録済みの環境では、今回の依頼とともに次の一つの入口を使います。

~~~text
Plan Modeスキル（$plan-mode）を使い、現在の依頼と文脈を調査・検討して、計画を提示してください。変更や実行はせず、計画提示で止めてください。
~~~

短い入力から、必要な深さ・比較・仮説・説明をAIが案件に合わせて選びます。未整理の意図の言語化も対象にし、実装計画だけへ強制収束させません。現在の禁止・STOPを保持し、その後に明確な実行承認があれば承認範囲へ進みます。

共有本体は[SKILL.md](SKILL.md)、表示名と同じ入口文は[agents/openai.yaml](agents/openai.yaml)に保持します。Queryの意味を独立した規則群へ増やさず、表示設定との文字列一致を改訂時に確認します。別の_queryファイル、旧Runtimeの巨大連結、追加の状態管理者は作りません。他AIでは本体URLと現在の依頼を渡し、導入環境の規約に従って使います。URLの提示だけで導入完了とはしません。
