# 使い捨て単一HTML / disposable-html

ArkのX投稿を、外部接続のない使い捨て単一HTMLへコンパイルするスキルです。投稿の種類は問いません。正本の手順は [SKILL.md](SKILL.md) が持ちます。このREADMEは、いつ使うかと、コピーできる入口だけを持ち、手順本文は再掲しません。

`markdown-to-html` は、既存Markdownの意味を保った閲覧版です。`write-social-post` は、Xの原稿でありHTMLを出しません。このスキルは、そのどちらでもありません。

## 使わない場面

- Markdownを、内容を変えずにHTMLの閲覧版へするとき。
- Xの投稿原稿を書くとき。
- このスキルの手順を改訂するとき。改訂は、下の育成Queryからだけ行います。
- 入力がX投稿ではない、一般のWeb制作。

## 生成Query

HTMLを一枚出すとき、この入口だけを渡します。育成の話は混ぜません。

~~~text
宛先：この依頼を受け取ったAI。

Goal:
渡したX投稿を、使い捨て単一HTMLへコンパイルする。

方法:
- Skillを直接利用できない場合は、共有原本を実際に全文読んで適用してください。
  https://github.com/yusukefujiijp/ai-project/blob/main/skills/disposable-html/SKILL.md
- 必須Sourceの取得切れは未読箇所から回収し、推測で手順を補わないでください。
- このREADMEの育成手順は読まないでください。見本の数字・価格・分数は持ち込まないでください。
- 入力の投稿と、投稿が自分で挙げた出典だけを使い、SKILL.mdの出力契約に従ってください。

完了条件:
- 三行のあと、完全なHTMLが一つある。
- HTML以外の解説を足していない。

Mode:
実行。この投稿のHTMLを一つ出すことだけを行う。
~~~

## 育成Query

実験で一枚が壊れたときだけ、この入口を使います。生成と同時に使いません。

~~~text
宛先：この依頼を受け取ったAI。

Goal:
disposable-html の手順を、観察された一つの失敗に対する一文の置換として返す。

方法:
- 現行手順を全文読んでください。
  https://github.com/yusukefujiijp/ai-project/blob/main/skills/disposable-html/SKILL.md
- このREADMEの境界を守ってください。手順本文は書き写して返さないでください。
- 失敗を一つに分類してください。床が割れたら、床の一文を置換する。器具の選択が違うなら、器具の一文だけを置換する。その投稿の言い回しだけなら、手順は変更しない。投稿の事実が違うなら、先に投稿を直す。
- 全文の書き換え、節の追加、見本の数字・価格・分数の書き戻し、あるAIの口調の採用は、不採用として理由を分けてください。
- 採用する置換は一つだけです。正本への保存は、このQueryの範囲外です。

完了条件:
- 置換する一文と、置換後の一文が並んでいる。手順を変えない場合は、変えない理由がある。
- 不採用にした案と、その理由が分かれている。

Mode:
提案。共有原本は変更しない。
~~~

## 形成

2026-11-25、YusukeJPが、X投稿から使い捨て単一HTMLを出す手順を、複数のAIで一文ずつ育てる正本としてスキル化することを採用した。生成の手順と、育て方のメタを同じ本文に置くと、HTMLを出す係が手順の改訂を始める。そのため手順はSKILL.md、入口と境界はこのREADMEが持つ。

この記録は共有原本への追加方針である。GitHubへの保存、各AIへの登録、実際の起動、読者の理解は、それぞれ未確認として分ける。通常利用のたびに、このスキルを自分で書き換えない。
