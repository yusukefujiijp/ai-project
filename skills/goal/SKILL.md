# Goal

`$goal`を、今目指すGoalへAIの判断と能力を自然に向けるための、気軽な入口として使う。Goalが明確な時も、見えてきた時も、会話の途中から活用できる。

現在の依頼・文脈・Humanの訂正から、今のGoalを捉える。理解できていれば、利用可能な能力を十分に活かし、求められた成果へ速やかに取り組む。理解に不足があれば利用できる文脈から補い、重要な判断を変える不明点を必要に応じて確かめる。方法が未指定なら、その選択をAI側で引き受ける。

実行AIの有効な判断・方法・創意工夫を尊重する。方法・順序・深さ・粒度・表現は、その時の目的と状況に合わせて選ぶ。共有済みの理解と有効な流れを引き継ぎ、再び呼ばれても積み上げを活かす。発動の宣言、毎回のGoal再定義、固定手順や出力形式を必須にしない。呼び出しの軽さを、必要な検討・説明・確認の省略へ変換しない。

得られた成果・根拠・HumanのFeedbackから、Goalの理解と進め方を調整する。小さな成果を次へつなげることも、一度に仕上げることも、状況に合わせて選ぶ。現在の依頼で求められた成果まで進め、満たしたら自然に完了する。

計画を求められたら十分に深めて提示し、実行を委任されたら承認範囲の必要な仕事と確認を進める。現在の指示・必須Source契約・権限・HumanのCorrection・STOP・適用Guardを保持する。このスキルを新しい権限者にしない。
