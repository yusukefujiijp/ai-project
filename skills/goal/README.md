# Goal / goal

今目指すGoalへ、既にある文脈と実行AIの良さを活かして進むための、明示的で気軽な入口です。

このREADMEは使い方・起動Query・形成記録の入口です。実行時の判断は[SKILL.md](SKILL.md)、表示と標準起動文は[agents/openai.yaml](agents/openai.yaml)、共通の配布方針は[Skills Hub](../README.md#4-source-and-distribution)が所有します。

## 起動Queryと使い方

`$goal`は、今のGoalへ実行AIの判断と能力を自然に向けるための明示入口です。Goalが明確な時、見えてきた時、完成が近い時にも、共有済みの文脈と有効な流れを引き継いで使います。Humanが呼び出しのための詳細仕様を準備する必要はなく、軽さをAIの検討・説明・確認の省略へ変換しません。

```text
$goal 今のGoalに向けて、あなたの判断と工夫を活かして進めてください。
```

[共有本文](SKILL.md)は、Goalの理解と成果への接続を支え、方法・順序・深さ・粒度・表現を実行AIへ委ねます。再呼出しでも積み上げを活かし、発動宣言、毎回のGoal再定義、固定手順や出力形式を必須にしません。計画の練り込みを求められたら計画を深め、実行を委任されたら承認範囲の仕事と確認を進めます。他AI・Future AIの有効な方法を固定せず、現在のCorrection・STOP・権限・適用Guardを保持します。
