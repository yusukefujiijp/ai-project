# SNS投稿の全文取得 / read-social-post

X/Twitterなどの投稿URLから対象本文の全文を取得し、依頼された読解・要約・検証・執筆につなぐスキルです。URL一つを入口にし、最初からHumanへ全文コピーを要求しません。

## 起動Query

今回の対象や場面とともに使います。次は現行UIの標準起動文です。

```text
$read-social-post で、この投稿URLから本文を末尾まで取得してください。
```

## 共有用Query

導入先を限定しない共有用の入口です。上のUI用起動文と用途を区別します。提示やコピーだけで、別AIへの送達・理解・実利用が成立するわけではありません。

```text
【公開投稿URLから、確認できた範囲を構造化して読む】

宛先：このQueryをHumanが直接入力するThreadのCurrent AI
Version：v001

- Humanが今回提示した投稿URLと、求めている成果を対象にしてください。投稿本文の手動コピーを開始条件にしないでください。URLが提示されていない場合は、対象URLだけを確認してください。

- read-social-postを利用してください。共有原本：
  https://github.com/yusukefujiijp/ai-project/blob/main/skills/read-social-post/SKILL.md

- 直接利用できない場合は、共有SKILL.mdを実際に全文読んで適用してください。登録版を使う場合も、今回必要な共有原本との対応を確認し、旧登録版を更新済みと推定しないでください。

- X/Twitterの適用対象では、SKILL.mdが指定する統合プロトコルを全文読み、現在のHuman指定と確認できる採用状態に従ってください。旧Grok案の具体指示を独立して併用せず、API v1の利用を旧案への回帰と扱わないでください。

- 適用される必須Source・読取順・Identity・Binding・EOFを保持し、取得・表示切れを回収してください。同一性と適用条件を確認できる自身の読解は再利用できます。必須資料を取得できなければ、不足・影響・最小の回復方法を示し、未読を読了済みと扱わないでください。

- 対象の同一性と依頼範囲を確認し、本文・数値・引用や記事・メディアの確認状態を区別してください。取得できた範囲から依頼された読解・要約等へ進み、未確認の内容や成功を補わないでください。

- Hostの取得規則、アクセス制御、現在の依頼の権限、Plan-only、STOPを保持してください。保存・設定変更・外部送信を、このQueryから追加しないでください。

- 完了条件は、依頼範囲を満たした結果、または取得できた範囲・不足・影響が正確に分かる結果が返ることです。今回の結果を、別投稿・別AI・別環境での成功保証へ広げないでください。
```

## 使い方と担当原本

対象の投稿URLを今回の依頼へ添えます。取得済みの本文や情報が、対象・依頼範囲・鮮度の条件を満たす場合は再利用します。本文が提供済みでも、依頼に必要なメディアや数値まで取得済みとは扱いません。

[SKILL.md](SKILL.md)が対象と依頼範囲を判断し、適用する取得手順へ接続します。X/Twitter公開投稿のFxTwitter方式は、[統合プロトコル](references/fxtwitter-protocol.md)が、経路・抽出・照合・成功判定・失敗時の扱いを所有します。他SNSへ同じURL変換やJSON構造を適用しません。

改訂版を適用する範囲では、旧Grok案の具体的な運用指示を独立した現行ルールとして併用しません。API v1は改訂版内部の互換経路であり、旧案への回帰ではありません。

取得方法の原本を読むことと、実際に取得を実行する権限は別です。現在の依頼、Plan-only、STOP、Hostの制約を保持します。
