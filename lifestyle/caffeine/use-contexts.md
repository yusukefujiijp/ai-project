# Caffeineの使い所 — 場面・条件・経験をつなぐ

## 2. 帰宅後の二つのモデルケース

### 2.1 共通して見えてきたこと

本人が示した二場面には、外での工程が終わった後、自宅で即仕分けするという共通点がある。AIはこれを、**外で済ませたことを、家で使える・整った状態へつなぐ接続**として整理した。この見立てはS1の `home-sorting-bridge` にCandidateとして記録している。

ここではCaffeineの用途に、具体的な行動の行き先がある。単に目が覚めたという感覚と、仕分けへ着手し進めたことを、同じ成果として自動判定しない。一方、本人が主観的な好結果を報告したら、その評価は尊重し、毎回新しい検証Taskを要求しない。

### 2.2 共通性と違いを両方保持する

洗濯物の仕分けと、買い物品の冷蔵・冷凍・常温等の扱いは同一ではない。この分類はAIが示す一般的な違いの例であり、その回の買い物内容を観測したという意味ではない。

支えたい行動の時点と、摂取する時点は分けて考える。「即仕分け」を、コーヒーの準備・飲み終わり・効果待ちの完了まで始められない行動へ変えない。量・時刻・現在の適否は、この用途発見だけでは決まらない。

仮に同じ帰宅時に洗濯物と買い物袋があっても、一つの帰宅後の場面として扱える。二つの用途を、一作業一杯・二回摂取へ変換しない。これは将来への解釈であり、同時に持ち帰ったという本人報告ではない。S1：`action-and-timing / shared-return-opportunity`。

### 2.3 想起の入口

[Ark Recall Portalのitems](../../ark-recall-portal/items.json)には、共通Scene `return-home-sorting` と、`home-laundry-caffeine-use / home-shopping-caffeine-use` がある。「洗濯物を持ち帰った」「買い物から帰った」等の場面から、対応する発見と条件へ戻れる。

Portalは必要な場面で思い出す入口、本フォルダはCaffeineというテーマを深める入口、S1は原発言とその時点の解釈を保持する原本である。自然な想起や生活上の効果の確認は、この導線の保存と分ける。

## 3. 起床・屋外・休日の記録から持ち帰るもの

### 3.1 起床時：手段と、手段が置かれた構造

S2は、起床と再睡眠の双方に利益があるというHuman Correction、事前の条件付き判断、身体的な手掛かりへの接続、実生活での成功報告という形成を保持している。ガムはその構造の中で用いられた。

持ち帰れる問いは、**今は方向を選ぶ段階なのか、選んだ方向を思い出す段階なのか、実際の着手へつなぐ段階なのか**である。これは事例からのAIの解釈であり、薬理的効果の分離検証ではない。S3の `s4` にある起床からAI活用への好調という本人評価も、その当時の報告として保つ。

### 3.2 屋外：好結果と、その場の条件

S3では、微糖コーヒーを選び、眠気を取り払いOutdoor WorkoutとAI活用への集中に一役買ったと本人が評価した。本人は当時、朝食未摂取も報告し、BetterとBestを区別していた。本人による糖分不足・血糖等の説明を、実測や医学的な因果説明として採用しない。

残量を自宅へ持ち帰ったという報告と、次回は無糖で試したいという意向も残る。前者は報告された行動、後者は当時の予定であり、後の試験結果を補完しない。S3：`coffee-remainder-home / unsweetened-test-plan / s30 / s31`。

ここから得るAIの見立ては、**同じCaffeineでも、支えたい行動と同時に成立していた条件を組にして読む必要がある**ということ。量・製品・食事条件の具体的な選択は現在の依頼と根拠から判断する。

### 3.3 休日：反省を、判断を育てる根拠として残す

S4が直接支えるのは、本人が以前の休日のタイミングを大きく間違えたと振り返ったこと。この短い発言だけから、失敗の原因、最適な摂取時刻、休日の普遍的ルールを作らない。

成功報告とタイミングへの反省を併せて読むと、長期テーマとして蓄積する価値が見える。成功時と反省時の条件を比較し、何が成立条件を変えるかを今後の報告から見分けていく整理が有用、とAIは考える。

## 4. コーヒー・ガム等を一つのテーマで扱う意味

本人は今回、コーヒーとガム等をCaffeine系としてまとめることを指定した。横断して扱うのは目的・使い所・経験・判断条件である。形態や製品固有の条件は、それぞれの根拠へ戻って扱う。

- 同じ場面でも、準備や携帯、本人の希望、製品の表示情報等が判断に関わり得る。
- 一つの形態の好結果を、別の形態・製品・使用時点へそのまま移植できるかは、別の問いである。
- 具体的な製品比較・量・時間の検討が必要になった時は、READMEの確認済み共通参照を使い、判断に必要な差分を現在の情報と一次資料から確認する。未調査の比較値や固定摂取量を作らない。

これらは、今回の資料構成を導くAIの整理である。新しい身体Trial・毎日の記録義務・専用Skillの新設を必須条件にしない。Current Humanの目的と、自然な報告・Correctionに合わせて深める。
